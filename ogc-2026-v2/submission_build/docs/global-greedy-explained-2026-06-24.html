한 줄 요약
베이를 미리 정하지 않는다. 블록을 순서대로 하나씩 꺼내, 모든 베이에 실제로 놓아보고 지각·부하·선호를 합친 marginal 점수가 최소인 베이에 확정. 배정은 이 과정의 결과(emergent)다. 한 번 놓으면 그 위치 그대로 굳히고, 마지막에 CP-SAT timing으로 시각만 마감.

0. 큰 그림

블록을 순서(blend)대로 하나씩:
  ┌ 모든 fit 베이에 place_one 시도
  │    → 각 베이의 품질 위치 + 예상 지각
  └ marginal(지각·부하·선호) 최소 베이에 확정
모두 배치 후
  → CP-SAT timing 으로 entry 시각 재최적화(z1 마감)
  → postproc(txyo) 로 미세 다듬기

1. 배치 순서 — blend

order = 블록을 (release + 0.5·processing) 오름차순
        OGC_ORDER=blend, set2 +9.2% vs EDD
왜 — 일찍 들어올 수 있고(release 작고) 빨리 나가는(처리 짧은) 블록을 먼저 놓는다(exit 임박 우선) → 시간축이 깔끔하게 정리돼 뒤 블록들이 들어갈 자리가 남음. (EDD=마감 빠른 순 보다 좋았음.)

2. 블록마다 — 모든 베이 시도 → marginal 최소

for 블록 i (순서대로):
  best = None
  for 각 fit 베이 j:
     rec = place_one(i, 베이 j)      # 그 베이의 품질 위치
     if rec 없음: skip
     sc = w1·tardy + w2·Δz2 + w3·(smax − 선호[j])
     best = sc 최소인 (j, rec)
  best 베이에 rec 확정 (재패킹 없음)
  배정[i] = best 베이

marginal 점수 뜯어보기

  • w1·tardy — tardy = max(0, rec.exit − due). 이 블록을 이 베이에 놓으면 얼마나 늦나.
  • w2·Δz2 — 이 블록을 더하면 베이 간 작업부하 불균형이 얼마나 커지나.
  • w3·(smax − 선호[j]) — 이 베이가 선호 베이에서 얼마나 벗어나나(선호도 페널티).
세 항의 가중합이 최소인 베이를 고름 → 배정이 emergent.
★ 여기가 약점
tardy가 myopic — "지금 이 블록만" 본 exit 기준이라, 나중에 같은 시간창에 들어올 블록이 만들 크레인 직렬화를 못 본다. 게다가 w1이 거대(set2 수천~3만)해서 작은 w3를 자릿수로 깔아뭉갬.
→ 이걸 "정확한 z1 피드백"으로 고치려던 게 M1·M2인데, 배정이 이미 near-optimal이라 재배정은 더 나빠져 실패(구조벽).

3. place_one — 한 베이에 어떻게 놓나

한 블록을 한 베이의 현재 상태에 가장 이른·가장 조밀한·크레인 가능한 자리로 증분 배치. temporal_pack.py:574
1진입 시각 후보 
lo = max(release, 마지막 진입시각)
cand_t = {lo} ∪ {기존 블록들의 exit 시각 중 lo 이후}
         (가장 이른 시각부터 시도)
블록이 들어갈 만한 시점 = 출시 직후 + 기존 블록이 빠져 자리가 나는 시각들.
2각 시각 t 에서 위치 찾기 
present = t 시점에 베이에 있는 블록들 → 점유 그리드
각 방향(회전) × BL 위치 후보:
   BL = bottom-left (각 행의 leftmost 빈자리, 몇 개)
   채점 = contact (기존 블록·벽·바닥에 얼마나 붙나)
          많이 붙을수록 빈틈없이 조밀
3게이트 통과 검증 
① crane_ok  : 크레인이 위에서 넣을 수 있나 (j≥k)
② trap_ok   : 이 블록이 남을·뺄 길을 막지 않나
③ check_entry: 공식 체커 진입 가능 게이트
contact 점수 높은 순으로 정렬 → 게이트 통과하는 첫 위치 채택.

못 놓으면 최후의 보루: 빈 베이 시각에 강제 배치(맞는 베이면 항상 가능).

4. 그 다음 — CP-SAT timing

모든 블록 배치가 끝나면 위치·배정은 고정하고, parallel_timing(CP-SAT)이 각 블록 entry 시각을 재최적화해 z1을 마감한다. (그리디의 tardy는 "어느 베이"만 흔들고, 실제 z1은 이 timing이 정한다.)
→ timing 상세: cpsat-timing-and-x-explained / cpsat-xt-ranges HTML 참고.

5. 핵심 직관 3가지

  1. 배정은 emergent — "이 블록 어느 베이"를 미리 안 정하고, 모든 베이에 놓아본 marginal로 결정.
  2. 한 번 놓으면 굳힘 — 위치는 재패킹 안 함(비가역). 이후 timing=시각만, postproc=미세 좌표/크레인 조정.
  3. 품질 배치 — place_one은 그냥 빈자리가 아니라 가장 이른 시각 + contact 최대(조밀) + 크레인 가능 위치를 고름. 그래서 이미 꽤 좋은 배정이 나오고, 그래서 사후 재배정(M1·M2)이 못 이긴다.
