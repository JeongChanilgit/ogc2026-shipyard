H0 — 확정 진단 (모든 가설의 근본). 현재 두 패커(fastfloor._ft_search_pos, box-decomp _bl_fit_cells)는 좌하단(Bottom-Left) 그리디다: 후보(벽+맞닿는 모서리+그리드폴백)를 (Y,X) 오름차순 정렬해 가장 낮고-왼쪽인 feasible 위치를 첫 번째로 채택, 블록을 하나씩, 백트래킹·전역밀도목적 없음. ⇒ 틈(gap)을 남기고 → spill 과다 → z3 패배. 경쟁자는 이걸 안 한다. 아래 H1~H13은 전부 "좌하단 그리디를 [방법]으로 대체/보강하면 밀도↑ → z3↓ → 경쟁자 추월"을 검증한다.
공통 검증 프로토콜 (모든 가설).
1단일-베이 self-test: 한 베이에 고정 블록셋을 패킹 → 밀도(점유 블록 수 또는 잔여 면적) + ft_tard을 BL 대비 측정. (가장 빠른 신호)
2mini-gate: prob_13/14/20(최대 z3 격차)에 적용 → z3·obj가 떨어지나? (fail-fast 선별)
3full set1 gate: _fstest.py/eval.py --set SET1 vs baselines/hybrid_set1.json. 채택 게이트.
게이트(공통): set1 총 obj↓ · feasible 유지 · never −1(wall≤TL) · best-of 무회귀 · OGC_* gated · INSIGHTS 기록(반증도 보존). 측정은 env python 직접 실행(…/envs/ogc2025/python.exe; conda run = 4워커 CP-SAT 크래시).

Phase 1 — 빠른 검증 (좌하단 직접 대체)

H1B · 최대레버spyrrow/sparrow (SOTA 네스팅, 전역 GLS) → 베이 패킹을 전역 최적으로 대체
가설좌하단 그리디 대신 sparrow의 Guided-Local-Search 전역 압착을 쓰면 같은 블록을 2~4× 조밀하게 → spill 급감 → z3가 경쟁자 수준으로.
예측prob_13 z3 805→≤450, prob_20 z3 1336→≤500, obj가 경쟁자 근접/추월.
검증① eval env(Linux x86_64, py3.12) wheel 설치 가능? 먼저 확인(사용자 승인 필요 — 외부패키지). ② 베이 footprint→spyrrow Item 변환, 가장 붐비는 시간슬롯 기준 패킹, 밀도 vs BL. ③ 통과 시 zip에 wheel bundle(서버 무인터넷).
리스크wheel 플랫폼/번들 · 정적 패킹이라 시간슬롯 분리 필요 · 15MB 제한.
H2A · 즉시Diagonal-Fill — 좌하단에 우상단(TR) 후보 추가 (Kwon&Lee 2015)
가설BL 단일 방향 대신 BL+TR 양방향 슬라이드 후보를 더하면 양끝에서 채워 틈↓ → 밀도↑.
예측congested 베이에서 ft_tard·z3 소폭~중폭 감소, 무회귀.
검증_ft_search_pos 후보생성에 우상단 벽/모서리 + TR 정렬키 추가(또는 BL/TR 두 정렬 best-of). 단일-베이 밀도 측정 → mini-gate.
리스크낮음(작은 변경). 후보 4096 상한 관리.
H3ANFP-BLF — 실제 폴리곤 No-Fit-Polygon 후보 (bbox/셀 → 폴리곤 인터로킹)
가설bbox/unit-cell 충돌은 폴리곤보다 큰 영역을 금지 → 오목부에 들어갈 블록을 막는다. NFP 경계 후보(맞닿는 실제 위치)를 쓰면 인터로킹 → 밀도↑.
예측오목 블록 많은 베이에서 밀도 유의 향상, z3↓.
검증pyclipper.MinkowskiSum으로 쌍별 NFP 사전계산, 후보=NFP 꼭짓점, shapely.intersects 정확 검사. 단일-베이 밀도 vs BL. (오목 폴리곤은 볼록분해.) ※ 외부패키지 pyclipper 승인 필요.
리스크오목 분해 복잡도 · NFP 전처리 O(n²) 시간.
H4ACP-SAT add_no_overlap_2d + energetic 파라미터 — box-decomp z1 천장 재시도
가설box-decomp의 수동 BoolOr(약한 전파) 대신 add_no_overlap_2d + use_energetic_reasoning_in_no_overlap_2d·use_area_energetic_reasoning·use_timetabling를 쓰면 강한 전파로 z1 천장(100~190) 돌파.
예측prob_13 preferred z1 152→대폭↓ (이전 cumulative로 300→152까지 됨, 더 내려갈지).
검증box-decomp rect-decomp을 interval로 재배선, 시간겹침 쌍 조건부 2d-no-overlap. prob_13 preferred z1 측정 vs 152.
리스크재formulation 공수 · no_overlap_2d는 직사각형만 → rect-decomp 품질 의존.
H7A/BGRASP/Beam 배치 순서 최적화 — 순서가 BL 밀도를 30~50% 좌우
가설같은 BL 패커라도 블록 투입 순서를 바꾸면 밀도가 크게 달라진다. 현 best-of-5-orders를 GRASP(랜덤그리디+LS)/beam으로 확장하면 더 조밀한 순서 발견.
예측congested 베이 ft_tard 추가 감소(현 5-orders 너머).
검증_pack_bay_copresent의 orders 생성을 GRASP/beam으로 교체, best-of. 단일-베이 → mini-gate.
리스크낮음. 시간예산(순서×패킹).

Phase 2 — 밀도 강화 로컬서치

H5 · Raster Penetration Map (FFT)
고해상도 IFR∧¬NFR 비트마스크(5~10px/단위), NFR을 FFT cross-correlation O(N log N)로. 옛 "굵은 unit-raster" 반증과 다름. 예측: 더 촘촘한 충돌→밀도↑. 검증: numpy 비트맵, 단일-베이 밀도.
H6 · Jostle / Ejection-Chain
놓인 블록 빼고 큰 블록 삽입→쫓겨난 것 재삽입 연쇄. 그리디 순서 고착 탈출. 예측: 초기해 대비 밀도↑. 검증: NFP+shapely, SA 외부루프, 단일-베이.
H11 · ALNS 밀도 (PSLAP)
창 내 k블록 위치+ENTRY 동시 파괴-수리(현 reassign의 공간-인식판). 예측: 전역 재배치로 z3↓. 검증: _solve_reassign 확장, full set1.

Phase 3 — 구조적 (높은 천장, 큰 공수)

H8 · LBBD (branch-and-check)
마스터(CP-SAT 배정+시간) ↔ 서브(폴리곤 비겹침) no-good cut 피드백. EJOR-2024 구조 동일. 타이밍 결정 시 배치가능성 인식 = 경쟁자 핵심 루프. 검증: 마스터+shapely 서브+lazy cut, mini-gate.
H9 · GLS-STA 4D (Caprace)
조선 실증 +12.7%. FLS를 블록 경계점만 탐색. 크레인-후크-높이 = OGC 크레인 직접대응(문헌 유일). 검증: scipy/numpy GLS, f=Σoverlap 최소화.
H10 · Gurobi separation-line MIP
쌍별 분리직선/수직슬라이스 = SOTA 불규칙패킹 MIP. 서버 풀-Gurobi 소형베이 정확해. 검증: 베이별 10~30블록, 로컬은 구조만(2000변수).
H12 · 표준각(15°) 근사 + GA
폴리곤을 15°배수 내각으로 단순화→준직사각형. 검증: 이산화+GA, 정수격자 정합.
H13 · 3D-sRCPSP cumulative
co-present Σarea ≤ bay area energetic(이미 box-decomp에 cumulative 추가됨)을 확장. 검증: OR-Tools cumulative, 근사 하한.
⚠ 병행 필수 — set2 −1 (실측). legacy가 set2 시간초과: prob_25 183.7s@TL120, prob_26 161.6s@TL120 → 서버면 −1. 모든 신규 패커는 set2에서도 never −1 보장(하드 데드라인+fallback). ALL40 실점수엔 set1 0.3M보다 이게 더 위협.

1. H2(Diagonal-Fill)·H7(순서) — 즉시, 외부패키지 불필요, 좌하단 직접 보강 → 빠른 신호.
2. H1(spyrrow)·H3(NFP) — 외부패키지(사용자 승인 필요: spyrrow/pyclipper). 최대 밀도 레버.
3. H4(CP-SAT energetic)·H5(raster-FFT)·H6(jostle) — 중간 공수.
4. H8(LBBD)·H9(GLS-STA)·H11(ALNS)·H10(Gurobi) — 구조적, 높은 천장.
