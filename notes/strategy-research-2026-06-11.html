3 5대 발견

F1
prob_13 비단조 원인 = floor 경로 기존 가설 기각

tl=100 전용 adaptive raster floor(발동조건 1.2e-3·n²>0.4T → n=250이면 T<187.5)가 더 좋은 attractor 도달: obj@100=245,705 (z1=1) vs obj@300=obj@1000=330,342 (z1=10, 3런 동일=결정적 함정).

기존 핸드오프 가설("마지막 단계 해 채택 문제, incumbent tracking으로 수정")은 데이터로 기각. consider() 게이트는 obj-단조이므로 문제는 "retention 실패"가 아니라 "도달 실패" — tl≥300 경로는 245K-class 해를 한 번도 본 적이 없다(fast floor 트리거 조건 1.2e-3·n²>0.4T: n=250이면 T<187.5s에서만 발동). "best-full-obj-across-trajectory retention" 가설은 기각. 확정 검증은 OGC_STAGE_TIMING(STAGE_OBJ) 계측 1런이면 충분. 올바른 수정은 floor racing(→T1): raster floor를 tl 게이트에서 해방해 긴 tl에서도 경쟁시킨다.

F2
PP_MULTISTART = 기각 재확인 (2026-06-10 확정) NEGATIVE 확정 · 재시도 금지

2026-06-10 세션에서 이미 NEGATIVE 확정, gated OFF 유지. 근본 원인: postprocess가 수렴이 아니라 budget을 fill함 — tl=900에서 1 pass가 ~700~880s 소비 → self-calibrating guard가 2nd pass를 거부 → 재시작이 거의 발동 안 함. 발동해도 chop-vs-variance trade가 인스턴스 의존(prob_6 variance-bound ✓ / prob_19 time-bound ✗) → clean default 불가.

이번 재집계도 혼재 재확인: prob_12 ON min 101,094 (OFF 116,564 대비 −13.3%, z1 1→0) / prob_6 동등(87,497) / prob_19 ON 86,252 vs OFF 80,846 (+6.7% 열위). 게다가 plateau600(tl=600) 76,472가 tl=900 OFF보다 좋음 — 시간이 아니라 경로(attractor)가 지배한다는 증거.

교훈 → T3 설계 제약으로 명시: ① 재시작 단위가 너무 작았다(postprocess만 cold) → 파이프라인 전체 레플리카로 확대 필요. ② pass-단위 self-calibration은 budget-fill과 구조적으로 충돌 → 레플리카별 고정 예산 분할로 교체.

F3
변동의 메타 비용 재확인

쌍별 최대 ±13.4%, z1 0↔1 플립(ms900a/b prob_12). 단일런 A/B로 1~5% 레버 측정 불가. 과거 Front B 튜닝 기각(net −1.5%가 노이즈에 묻힘) 등 의사결정 자체를 흐려온 메타 문제.

모든 후속 트랙의 측정 전제 = T2(실험 결정화). T2 없이 T1~T5 효과 판정 불가.

F4
전역 재배정 함수 상태 확인 신규 판정

_temporal_reassign_redecode_verified(myalgorithm.py:3623, AddCumulative 면적-시간 용량 + 배정·entry 동시 변수)는 src 내 호출 0곳=dormant. 기각 이력(notes/z1-toggles.md:53): z1-frame area-balance 버전 — prob_20 921→356 작동하나 cum_level 231에 패배, aggressive 설정에서 z1 폭발 320 vs default 11.

z3-frame lexicographic 버전(z1 하드 고정 + min z3)은 미평가. 기각 사유(z1 폭발)를 제약으로 차단하는 재설계 가능 → T4.

F5

충돌 검사는 polygon-exact(Shapely, 공식 체커 동일)인데 후보 (x,y) 생성만 bbox 우상단 모서리 격자(baseline_greedy.py:283-335, myalgorithm.py:1039-1078) → 오목/테이퍼 맞물림 위치가 애초에 제안 안 됨.

문헌상 오목 형상 bbox 근사 밀도 손실 15~25% ⚠ 미검증 · 지식기반. Front B 이동 실패(선호 베이 '만원')의 일부는 bbox 후보 부족 artifact → 기하 개선이 z3 개선으로 직결(→T5 시너지).

F5: 오목 형상 bbox 밀도 손실 15~25%. Front B 이동 실패의 일부가 bbox 후보 부족. T4 decode test(CP-SAT 전역 재배정 기각 박스)가 z3 headroom을 packing-blocked로 확정했다면, 남은 z3 레버는 배정 "검색"이 아니라 packing 그 자체다 — 후보 다양화로 같은 배정이 더 빽빽하게 실현되면 Front B 이동 성공률과 z1 여유가 동시에 열린다. 기존 분석 도구의 "bbox→polygon 갭 = #1 레버" 판정과 합치. T4 삽입 성공률 피더이자 독립 z3 레버.
어떻게
배치 함수 O(i³)/block 핫패스 — 후보 증가=검사 비용 직결. 병합+K=80 캡 유지, 디코드 시간 회귀 감시.
검증 게이트
디코드 시간 +10% 이하 확인 후 z3 비교. 독립 병행 가능(T4 선행 불필요).
리스크
후보 증가가 전체 시간예산을 잠식 가능 → (i)부터 단계별.
T6 P2 제출·리더보드 전략 (지속)
무엇
안정 빌드 조기 제출(hourly 집계 반영). 리더보드로 경쟁 밀도 추정 → 분산축소 vs 평균개선 우선순위 동적 조정. 12h 쿨다운 제출 캘린더.
왜
R−nb 특성: 동점 무손해, −1 비대칭(≈R/2+1 손실). 안정성>최적성 불변. 상위권이면 mean 개선 우선, 중위 밀집이면 min 수확 우선 ⚠ 의사결정이론 · 지식기반.
검증 게이트
제출 전 tl=60/100 smoke test → −1 0건 확인.
리스크
12h 쿨다운 제약. 불안정 빌드 제출 = 점수 낭비.

5 시너지 맵 + 실행 순서

T2→[P0] 측정 전제 확립 (모든 트랙의 판정 기반). 첫 번째 실행.
T1→[P0, long-tl 전용] 싸고 확실, 1~2일급. prob_13 즉시 회수. floor 다양화의 첫 단계.
T3→[P1] T1의 floor 다양화를 레플리카 차원으로 흡수. 변동 구조적 수확. T5와 병행 가능.
T5→[P1] T3와 독립 병행 가능. packing-blocked z3의 직접 레버 + T4 삽입 성공률 피더.
T4→[P2 조건부] kill-test 통과 시에만 빌드. 실패 → 06-10 판정 영구 확정. 실행 순서 최후.
T6→[지속] 모든 트랙과 병행. 안정 체크포인트마다 제출.
