패킹·배치 — Bin Packing, 2D 직교, 이형 폴리곤

Bin Packing / Multiple Knapsack 부터 AddNoOverlap2D 기반 2D 직교 사각형 패킹, 방향(회전) 처리, Strip Packing, 이형 폴리곤의 격자 근사 전략까지 — CP-SAT로 공간 배치 문제를 모델링하는 완전 가이드. OGC 2026 베이(스트립) 내 블록 배치 문제와 직접 연결된다.

★ OGC 2026 관련성

베이 = Strip, 블록 = Rectangle(근사): 각 베이를 고정 폭·높이의 Strip으로 보고 블록을 사각형(또는 박스-분해 사각형 집합)으로 근사하면, AddNoOverlap2D로 공간 충돌을 직접 모델링할 수 있다. 방향 o(0°/90°)는 회전 후보 두 사각형 중 하나를 Boolean으로 선택하는 패턴으로 처리한다. 크레인 수직접근 규칙 j ≥ k(높이 층 j의 블록은 층 k ≤ j 블록보다 먼저 반출)는 y축(높이) 인터벌에 추가 선후 관계 제약으로 동형화된다. 단, 이형 폴리곤 밀도 측면에서 CP-SAT 박스패커는 Bottom-Left 휴리스틱보다 느릴 수 있다 — 박스분해 해상도와 시간 예산을 현실적으로 설정해야 한다.

1. Bin Packing 모델링

Bin Packing 문제: n개 아이템(무게 wi)을 최소 개수의 빈(용량 C)에 배정. OR-Tools는 MIP(SCIP 등)와 CP-SAT 양쪽 모두로 풀 수 있다. 용량 1D 제약만 필요하면 MIP가 일반적으로 빠르지만, 공간 제약(2D/3D)이 섞이면 CP-SAT의 interval-based 접근이 유리하다.

1.1 전통적 MIP 공식화

# OR-Tools MIP Bin Packing (SCIP backend)
from ortools.linear_solver import pywraplp

def solve_bin_packing():
    weights = [48, 30, 19, 36, 36, 27, 42, 42, 36, 24, 30]
    n        = len(weights)
    C        = 100                   # bin capacity
    m        = n                     # upper bound on bins (= n)

    solver = pywraplp.Solver.CreateSolver("SCIP")

    # x[i,j] = 1  :  item i goes into bin j
    x = {(i,j): solver.IntVar(0, 1, f"x_{i}_{j}")
         for i in range(n) for j in range(m)}
    # y[j] = 1  :  bin j is used
    y = {j: solver.IntVar(0, 1, f"y_{j}") for j in range(m)}

    # 제약 1: 각 아이템은 정확히 1개 빈에
    for i in range(n):
        solver.Add(sum(x[i,j] for j in range(m)) == 1)

    # 제약 2: 빈 용량 — y[j]*C >= 총 무게 (Big-M 대신 용량을 계수로)
    for j in range(m):
        solver.Add(
            sum(x[i,j] * weights[i] for i in range(n)) <= y[j] * C
        )

    solver.Minimize(solver.Sum(y[j] for j in range(m)))
    status = solver.Solve()

    if status == pywraplp.Solver.OPTIMAL:
        print(f"최소 빈 수: {int(sum(y[j].solution_value() for j in range(m)))}")
팁 — CP-SAT로 Bin Packing 변환

아이템이 2D 공간을 차지하거나 Non-overlap 제약이 필요한 순간, 위 MIP 공식은 쓸 수 없다. 그 대신 아래 Section 3의 AddNoOverlap2D 기반 "하나의 큰 스트립" 패턴으로 전환한다.

1.2 CP-SAT Multiple Knapsack

Multiple Knapsack: 여러 빈(용량이 다를 수 있음)에 아이템을 배정해 총 가치 최대화. 각 아이템이 최대 1개 빈에 들어가는 것이 Bin Packing과의 차이. 

from ortools.sat.python import cp_model

def solve_multiple_knapsack():
    weights    = [48, 30, 42, 36, 36, 48, 42, 42, 36, 24, 30, 30, 42, 36, 36]
    values     = [10, 30, 25, 50, 35, 30, 15, 40, 30, 35, 45, 10, 20, 30, 25]
    capacities = [100, 100, 100, 100, 100]   # 5개 빈

    n_items = len(weights)
    n_bins  = len(capacities)
    model   = cp_model.CpModel()

    # x[i, b] = 1  :  item i is in bin b
    x = {}
    for i in range(n_items):
        for b in range(n_bins):
            x[i, b] = model.new_bool_var(f"x_{i}_{b}")

    # 제약 1: 각 아이템은 최대 1개 빈에 (at most one — 안 담겨도 OK)
    for i in range(n_items):
        model.add_at_most_one(x[i, b] for b in range(n_bins))

    # 제약 2: 빈 용량
    for b in range(n_bins):
        model.add(
            sum(x[i, b] * weights[i] for i in range(n_items))
            <= capacities[b]
        )

    # 목적: 총 가치 최대화
    model.maximize(
        cp_model.LinearExpr.sum(
            [cp_model.LinearExpr.term(x[i, b], values[i])
             for i in range(n_items) for b in range(n_bins)]
        )
    )

    solver = cp_model.CpSolver()
    status = solver.solve(model)
    if status in (cp_model.OPTIMAL, cp_model.FEASIBLE):
        for b in range(n_bins):
            items = [i for i in range(n_items) if solver.value(x[i, b])]
            print(f"Bin {b}: items={items}, "
                  f"weight={sum(weights[i] for i in items)}")
면적 하한 (Area Lower Bound)

2D Knapsack에서 bin 개수 하한을 빠르게 구하려면: lb = ceil(sum(w_i * h_i) / (W * H)). 이 값을 초기 빈 개수로 세팅하면 탐색 범위가 크게 줄어든다. CP-SAT에서 model.add(bins_used >= lb)로 주입.

2. Interval Variables — 4가지 타입

CP-SAT의 Interval Variable은 start + size == end를 항상 보장하는 특수 제약 객체다. AddNoOverlap / AddNoOverlap2D / AddCumulative에서 인자로 사용된다.

타입 생성 메서드 크기 Optional? 주 용도
일반 new_interval_var(start, size, end, name) 변수 X 시작·크기 모두 가변
고정 크기 new_fixed_size_interval_var(start, size, name) 상수 X 크기 고정, 전파 빠름
Optional new_optional_interval_var(start, size, end, is_present, name) 변수 O (Bool) 배치 여부 Boolean 제어
Optional 고정 크기 new_optional_fixed_size_interval_var(start, size, is_present, name) 상수 O (Bool) 크기 고정 + 배치 여부 가장 효율적 
from ortools.sat.python import cp_model
model = cp_model.CpModel()
W, H = 100, 50   # 컨테이너 크기
w, h = 20, 15    # 블록 크기 (고정)

# ① 일반 Interval — start·end 모두 변수
sx = model.new_int_var(0, W - w, "sx")
ex = model.new_int_var(w, W,     "ex")
ix = model.new_interval_var(sx, w, ex, "ix")

# ② 고정 크기 Interval — 가장 단순, 전파 효율 최고
sx2 = model.new_int_var(0, W - w, "sx2")
ix2 = model.new_fixed_size_interval_var(sx2, w, "ix2")

# ③ Optional — 배치 여부를 Boolean으로
placed = model.new_bool_var("placed")
sx3    = model.new_int_var(0, W - w, "sx3")
ex3    = model.new_int_var(w, W,     "ex3")
ix3    = model.new_optional_interval_var(sx3, w, ex3, placed, "ix3")

# ④ Optional + 고정 크기 — 2D Knapsack에서 권장
placed4 = model.new_bool_var("placed4")
sx4     = model.new_int_var(0, W - w, "sx4")
ix4     = model.new_optional_fixed_size_interval_var(sx4, w, placed4, "ix4")
함정 — AddNoOverlap2D 와 Optional

AddNoOverlap2D는 Optional Interval을 직접 지원하지 않는다. Optional interval을 NoOverlap2D에 넘기면 에러가 발생한다.
대안: new_optional_fixed_size_interval_var를 사용하면 is_present=False인 인터벌을 NoOverlap2D가 무시한다 (OR-Tools 9.x 이상에서 지원 — 버전 확인 필수).

3. AddNoOverlap2D — 2D 직교 사각형 패킹

model.add_no_overlap_2d(x_intervals, y_intervals)는 동일 인덱스의 (x_interval, y_interval) 쌍을 2D 직사각형으로 해석하고, 어떤 두 직사각형도 교차하지 않도록 강제한다. 1D NoOverlap보다 훨씬 강력한 LP 완화(projection + cumulative 강화)를 내부에서 자동 생성한다.

3.1 기본 패턴 — 모든 블록 배치 (필수)

from ortools.sat.python import cp_model

def pack_rectangles(container_w, container_h, rects):
    """
    rects: list of (width, height) tuples
    모든 직사각형을 컨테이너에 배치. 실현불가 시 INFEASIBLE 반환.
    """
    model = cp_model.CpModel()
    n = len(rects)

    x_starts, y_starts = [], []
    x_intervals, y_intervals = [], []

    for i, (w, h) in enumerate(rects):
        # 좌하단 좌표
        xs = model.new_int_var(0, container_w - w, f"xs_{i}")
        ys = model.new_int_var(0, container_h - h, f"ys_{i}")
        x_starts.append(xs)
        y_starts.append(ys)

        # 고정 크기 Interval — 크기가 이미 결정됐으므로 가장 빠름
        xi = model.new_fixed_size_interval_var(xs, w, f"xi_{i}")
        yi = model.new_fixed_size_interval_var(ys, h, f"yi_{i}")
        x_intervals.append(xi)
        y_intervals.append(yi)

    # 핵심: 2D 비겹침
    model.add_no_overlap_2d(x_intervals, y_intervals)

    solver = cp_model.CpSolver()
    solver.parameters.max_time_in_seconds = 60.0
    status = solver.solve(model)

    if status in (cp_model.OPTIMAL, cp_model.FEASIBLE):
        return [(solver.value(x_starts[i]), solver.value(y_starts[i]))
                for i in range(n)]
    return None   # INFEASIBLE

3.2 Optional Placement — 2D Knapsack

모든 블록을 강제로 넣지 않고 가치 합을 최대화하거나, 가능한 것만 배치하는 경우. new_optional_fixed_size_interval_var를 사용한다. 

def pack_2d_knapsack(container_w, container_h, rects, values):
    """
    rects : list of (w, h), values : list of int
    가능한 직사각형을 선택적으로 배치, 총 가치 최대화.
    """
    model = cp_model.CpModel()
    n = len(rects)

    placed_vars  = []
    x_intervals, y_intervals = [], []

    for i, (w, h) in enumerate(rects):
        packed = model.new_bool_var(f"packed_{i}")
        placed_vars.append(packed)

        # 배치 안 된 경우 좌표가 어디든 무방하므로 전체 도메인
        xs = model.new_int_var(0, container_w - w, f"xs_{i}")
        ys = model.new_int_var(0, container_h - h, f"ys_{i}")

        # Optional + 고정 크기: is_present=packed 이면 NoOverlap2D가 활성 취급
        xi = model.new_optional_fixed_size_interval_var(xs, w, packed, f"xi_{i}")
        yi = model.new_optional_fixed_size_interval_var(ys, h, packed, f"yi_{i}")
        x_intervals.append(xi)
        y_intervals.append(yi)

    model.add_no_overlap_2d(x_intervals, y_intervals)

    # 목적: 총 가치 최대화
    model.maximize(
        cp_model.LinearExpr.weighted_sum(placed_vars, values)
    )

    solver = cp_model.CpSolver()
    solver.parameters.max_time_in_seconds = 120.0
    status = solver.solve(model)

    results = []
    if status in (cp_model.OPTIMAL, cp_model.FEASIBLE):
        for i, (w, h) in enumerate(rects):
            if solver.value(placed_vars[i]):
                results.append((i, solver.value(...), solver.value(...)))
    return results
팁 — use_cumulative_in_no_overlap_2d

solver.parameters.use_cumulative_in_no_overlap_2d = True(기본 OFF)를 켜면 NoOverlap2D에서 각 축(x, y)에 대한 Cumulative 전파를 자동 추가한다. 전파가 강해져 불필요한 위치를 더 빨리 잘라내지만, 제약 처리 비용이 늘어날 수 있다. 작은 인스턴스에서는 ON, 대형 인스턴스에서는 실험으로 결정한다.

4. 방향(회전) 처리 — 0°/90° 선택

블록을 0° 또는 90° 중 하나로 배치할 수 있을 때, Boolean rotated 변수로 폭/높이 중 어느 쪽이 x축·y축 크기인지를 동적으로 결정한다.

4.1 선형 조건부 크기 (d-krupke CP-SAT Primer 패턴)

from ortools.sat.python import cp_model

def pack_with_rotation(container_w, container_h, rects):
    """
    rects: list of (width, height)
    0° / 90° 회전 허용. width != height 인 경우만 실질적 의미.
    """
    model = cp_model.CpModel()
    n = len(rects)

    xs, ys          = [], []
    xe, ye          = [], []
    x_sz, y_sz      = [], []   # 실제 배치 크기 (회전에 따라 결정)
    rotated         = []
    x_ivals, y_ivals = [], []

    for i, (w, h) in enumerate(rects):
        rot = model.new_bool_var(f"rot_{i}")
        rotated.append(rot)

        max_dim = max(w, h)
        # 배치 크기 변수
        sw = model.new_int_var(min(w,h), max_dim, f"sw_{i}")
        sh = model.new_int_var(min(w,h), max_dim, f"sh_{i}")
        x_sz.append(sw); y_sz.append(sh)

        diff = w - h
        if diff == 0:
            # 정사각형 — 회전 무의미
            model.add(sw == w)
            model.add(sh == h)
        else:
            # rot=0 → sw=w, sh=h  /  rot=1 → sw=h, sh=w
            model.add(sw == w - rot * diff)
            model.add(sh == h + rot * diff)

        # 좌하단
        x0 = model.new_int_var(0, container_w - min(w,h), f"x0_{i}")
        y0 = model.new_int_var(0, container_h - min(w,h), f"y0_{i}")
        x1 = model.new_int_var(min(w,h), container_w, f"x1_{i}")
        y1 = model.new_int_var(min(w,h), container_h, f"y1_{i}")
        xs.append(x0); ys.append(y0)
        xe.append(x1); ye.append(y1)

        xi = model.new_interval_var(x0, sw, x1, f"xi_{i}")
        yi = model.new_interval_var(y0, sh, y1, f"yi_{i}")
        x_ivals.append(xi); y_ivals.append(yi)

        # 경계 제약: 상단·우측이 컨테이너를 벗어나지 않도록
        model.add(x1 <= container_w)
        model.add(y1 <= container_h)

    model.add_no_overlap_2d(x_ivals, y_ivals)

    solver = cp_model.CpSolver()
    solver.parameters.max_time_in_seconds = 60.0
    status = solver.solve(model)

    if status in (cp_model.OPTIMAL, cp_model.FEASIBLE):
        return [
            (solver.value(xs[i]), solver.value(ys[i]),
             bool(solver.value(rotated[i])))
            for i in range(n)
        ]
    return None
함정 — 도메인 폭발 (Domain Explosion)

x_start의 도메인을 [0, container_w]로 잡으면 CP-SAT 내부 비트벡터가 container_w비트를 할당한다. 컨테이너 폭이 10,000이면 변수당 10K 비트 → 수천 개 블록에서 수십 MB 메모리, 전파 속도 급감. 반드시 [0, container_w - min_block_w]로 상한을 좁힌다. 이미 배치된 블록 위치로 도메인을 사전 제거하는 placement point 기법도 효과적.

함정 — 회전을 0°/90°로만 제한

CP-SAT는 기하 개념이 없다. 45°·임의 각도 회전은 직접 모델링 불가. 0°/90° 두 후보만 있는 경우 위 패턴이 동작하며, "두 크기 중 하나를 선택"하는 Boolean 선택으로 표현하면 충분하다. 그 이상의 각도가 필요하면 전처리로 후보 배치 테이블을 생성하고 CP-SAT는 테이블 선택만 담당.

5. Strip Packing — 폭 고정, 높이 최소화

Strip Packing: 고정 폭 W인 스트립에 모든 블록을 배치하고 사용 높이(makespan)를 최소화. 이 구조는 OGC 2026의 베이(고정 폭·높이)와 직접 대응된다.

5.1 단일 스트립, 높이 최소화

def strip_packing(strip_w, rects, time_limit=60.0):
    """
    rects : list of (w, h)
    목적 : 배치 높이 상한(strip_h) 최소화
    """
    model = cp_model.CpModel()
    n = len(rects)

    # 이론적 상한 = 모든 블록 쌓기
    h_upper = sum(h for _, h in rects)
    # 이론적 하한 = 총 면적 / 폭
    import math
    h_lower = math.ceil(sum(w*h for w,h in rects) / strip_w)

    strip_h = model.new_int_var(h_lower, h_upper, "strip_h")

    x_ivals, y_ivals = [], []
    for i, (w, h) in enumerate(rects):
        xs = model.new_int_var(0, strip_w - w, f"xs_{i}")
        ys = model.new_int_var(0, h_upper - h, f"ys_{i}")

        xi = model.new_fixed_size_interval_var(xs, w, f"xi_{i}")
        yi = model.new_fixed_size_interval_var(ys, h, f"yi_{i}")
        x_ivals.append(xi)
        y_ivals.append(yi)

        # 각 블록 상단이 strip_h를 초과하면 안 됨
        model.add(ys + h <= strip_h)

    model.add_no_overlap_2d(x_ivals, y_ivals)
    model.minimize(strip_h)

    solver = cp_model.CpSolver()
    solver.parameters.max_time_in_seconds = time_limit
    # 힌트: 면적 하한을 초기 upper bound로 설정
    # solver.parameters.solution_pool_solution_count = 5
    status = solver.solve(model)

    if status in (cp_model.OPTIMAL, cp_model.FEASIBLE):
        return solver.value(strip_h)
    return None

5.2 다중 빈 → "하나의 큰 스트립" 트릭

m개 빈(폭 W, 높이 H)에 분산 배치할 때, 빈 번호를 x축으로 확장해 단일 스트립 m*W × H로 변환. 빈 번호 변수 bi와 로컬 x좌표 xi를 링크해 "어느 빈의 어느 위치"를 동시 결정. 

def multi_bin_packing(W, H, m, rects):
    """
    m개 빈(각 W×H)에 모든 블록 배치, 사용 빈 수 최소화.
    """
    model = cp_model.CpModel()
    n = len(rects)

    # 전역 x 좌표 (0 .. m*W-1)
    xb1 = [model.new_int_var(0, m*W - rects[i][0], f"xb1_{i}") for i in range(n)]
    xb2 = [model.new_int_var(rects[i][0], m*W,     f"xb2_{i}") for i in range(n)]
    y1  = [model.new_int_var(0, H - rects[i][1],   f"y1_{i}")  for i in range(n)]
    y2  = [model.new_int_var(rects[i][1], H,        f"y2_{i}")  for i in range(n)]

    # 빈 번호 0..m-1
    b = [model.new_int_var(0, m-1, f"b_{i}") for i in range(n)]
    # 빈 내 로컬 x 좌표
    x = [model.new_int_var(0, W - rects[i][0], f"x_{i}") for i in range(n)]

    x_ivals, y_ivals = [], []
    for i, (w, h) in enumerate(rects):
        # 전역 x = 로컬 x + bin_no * W
        model.add(xb1[i] == x[i] + b[i] * W)
        model.add(xb2[i] == xb1[i] + w)
        model.add(y2[i]  == y1[i] + h)

        xi = model.new_interval_var(xb1[i], w, xb2[i], f"xi_{i}")
        yi = model.new_interval_var(y1[i],  h, y2[i],  f"yi_{i}")
        x_ivals.append(xi); y_ivals.append(yi)

    model.add_no_overlap_2d(x_ivals, y_ivals)

    # 사용 빈 수 = max(b_i) + 1 → 최소화
    z = model.new_int_var(0, m-1, "z")
    model.add_max_equality(z, b)
    model.minimize(z)

    solver = cp_model.CpSolver()
    solver.parameters.max_time_in_seconds = 120.0
    status = solver.solve(model)

    if status in (cp_model.OPTIMAL, cp_model.FEASIBLE):
        return [(solver.value(b[i]), solver.value(x[i]), solver.value(y1[i]))
                for i in range(n)]
    return None
팁 — "하나의 큰 스트립" 패턴의 이점

빈 번호별 별도 NoOverlap2D를 만들면 n개 빈 × NoOverlap2D 제약이 생긴다. 단일 전역 NoOverlap2D는 한 번의 propagation으로 모든 빈 간 충돌도 잡아낸다. 블로거(Erwin Kalvelagen, 2021)가 실험으로 확인: 전역 단일 제약이 분리 다중 제약보다 유의미하게 빠름.

6. OGC 크레인 j ≥ k 제약의 동형화

OGC 2026 크레인 수직접근 (j ≥ k)

베이 내 블록들이 여러 층(y축 높이)에 쌓일 때, 크레인은 수직으로 내려오므로 위층(y 큰 쪽) 블록이 먼저 반출돼야 아래층 블록에 접근 가능. 이를 CP-SAT로 모델링하는 두 가지 접근:

6.1 접근 A — Exit 시각 순서 제약

같은 x 구간에 겹치는 두 블록 i, j에서 블록 i가 블록 j 위에 있으면(y_i > y_j), 블록 i의 EXIT 시각이 블록 j의 ENTRY 시각보다 빨라야 한다. 

# 블록 i가 블록 j 위에 있으면 exit_i <= entry_j
# "위에 있음"을 CP-SAT로 표현하기 위해 Boolean 보조변수 사용

for i in range(n):
    for j in range(n):
        if i == j:
            continue
        # i가 j 위에 있는가? (y_start[i] > y_start[j] + height[j])
        above_ij = model.new_bool_var(f"above_{i}_{j}")

        # above_ij = 1  iff  ys[i] >= ys[j] + h[j]
        model.add(ys[i] >= ys[j] + heights[j]).only_enforce_if(above_ij)
        model.add(ys[i] <  ys[j] + heights[j]).only_enforce_if(above_ij.negated())

        # x축 겹침이 있으면서 위에 있으면 exit_i <= entry_j
        x_overlap = model.new_bool_var(f"xovlp_{i}_{j}")
        # x 겹침 조건 인코딩 생략 (xs[i] < xs[j]+w[j] AND xs[j] < xs[i]+w[i])

        both = model.new_bool_var(f"both_{i}_{j}")
        model.add_bool_and([above_ij, x_overlap]).only_enforce_if(both)

        model.add(exit_time[i] <= entry_time[j]).only_enforce_if(both)

6.2 접근 B — y 인터벌 순서를 NoOverlap으로 (단순화)

같은 x 범위에 공존하는 블록들의 반출 시각 인터벌을 1D NoOverlap으로 직렬화. 크레인이 한 번에 하나의 블록만 처리할 수 있다는 조건을 쉽게 표현. 

# 반출 시각을 "작업"으로 보고 1D NoOverlap
exit_intervals = [
    model.new_fixed_size_interval_var(exit_time[i], crane_duration, f"crane_{i}")
    for i in range(n)
]
model.add_no_overlap(exit_intervals)
# 크레인 처리 순서: 위층 블록의 exit가 아래층 entry보다 빠르게

7. 이형 폴리곤 패킹 — CP-SAT의 한계와 근사 전략

CP-SAT의 NoOverlap2D는 직사각형(axis-aligned rectangle)만 지원한다. OGC 2026의 블록은 이형 폴리곤이므로 직접 적용 불가. 실용적인 전략 3가지를 비교한다.

7.1 전략 A — 박스 분해 (Box Decomposition)

폴리곤을 여러 직사각형 집합 {R₁, R₂, …, Rₖ}의 합집합으로 근사. 각 직사각형을 별도의 interval로 등록하되, 같은 폴리곤에 속한 직사각형들은 동일 상대 위치를 유지하는 링크 제약을 추가한다. 

"""
폴리곤 i → 박스 분해 { (ox_k, oy_k, bw_k, bh_k) } (k = 0..Ki-1)
  (ox_k, oy_k) : 앵커 점에서의 오프셋
  (bw_k, bh_k) : 박스 크기
anchor = (xs[i], ys[i]) = 폴리곤 i의 기준 좌표
"""
from ortools.sat.python import cp_model

def pack_polygons_box_decomp(container_w, container_h, polygons):
    """
    polygons : list of list of (ox, oy, bw, bh)
    """
    model = cp_model.CpModel()
    all_x_ivals, all_y_ivals = [], []

    anchor_xs, anchor_ys = [], []

    for i, boxes in enumerate(polygons):
        # 앵커 좌표 (기준점)
        ax = model.new_int_var(0, container_w, f"ax_{i}")
        ay = model.new_int_var(0, container_h, f"ay_{i}")
        anchor_xs.append(ax); anchor_ys.append(ay)

        for k, (ox, oy, bw, bh) in enumerate(boxes):
            # 각 박스의 전역 좌표 = 앵커 + 오프셋
            bx = model.new_int_var(0, container_w - bw, f"bx_{i}_{k}")
            by = model.new_int_var(0, container_h - bh, f"by_{i}_{k}")
            model.add(bx == ax + ox)
            model.add(by == ay + oy)

            xi = model.new_fixed_size_interval_var(bx, bw, f"xi_{i}_{k}")
            yi = model.new_fixed_size_interval_var(by, bh, f"yi_{i}_{k}")
            all_x_ivals.append(xi)
            all_y_ivals.append(yi)

    # 전체 박스(모든 폴리곤의 모든 박스)에 NoOverlap2D
    model.add_no_overlap_2d(all_x_ivals, all_y_ivals)

    solver = cp_model.CpSolver()
    solver.parameters.max_time_in_seconds = 120.0
    status = solver.solve(model)

    if status in (cp_model.OPTIMAL, cp_model.FEASIBLE):
        return [(solver.value(anchor_xs[i]), solver.value(anchor_ys[i]))
                for i in range(len(polygons))]
    return None
함정 — 박스 분해 수가 늘면 interval 수 폭발

폴리곤 1개를 k개 박스로 분해 + n개 블록 → n×k개 interval. NoOverlap2D 내부 쌍 비교는 O((n×k)²) 비례. k=5, n=50이면 250개 interval → 31,125 쌍. 박스 분해 정밀도(k)와 실행 시간의 트레이드오프를 현실적으로 설정해야 한다.
OGC 관측치: k≥3인 박스분해 + T=120s → z1이 BL 휴리스틱보다 나을 수 있지만 set2 대형 인스턴스에서는 TL 초과 위험이 있다.

7.2 전략 B — 격자 셀 점유 (Raster / Grid Cell)

폴리곤을 해상도 Δ의 격자로 이산화해 점유 셀 집합으로 표현. 두 폴리곤이 동일 셀을 점유하지 않으면 겹침이 없다는 조건을 Boolean 변수로 인코딩. 

"""
격자 해상도 delta = 1 (정수 스케일링 후)
cell_occ[i][gx][gy] = 1  if  polygon i occupies cell (gx, gy) at anchor (0,0)
실제 배치 후: 폴리곤 i의 위치 (ax, ay) → 실제 점유 셀 = (ax+gx, ay+gy)
"""

def pack_raster(W, H, poly_cells, time_limit=60):

    poly_cells : list of frozenset of (gx, gy) — 각 폴리곤의 점유 오프셋 셀
    """
    model = cp_model.CpModel()
    n = len(poly_cells)

    ax = [model.new_int_var(0, W-1, f"ax_{i}") for i in range(n)]
    ay = [model.new_int_var(0, H-1, f"ay_{i}") for i in range(n)]

7.3 전략 C — 후보 위치 사전 생성 + Set Packing

이형 폴리곤의 가능한 배치 후보 위치를 사전에 계산하고, 각 후보를 Boolean 변수로 표현해 "선택된 후보들이 서로 겹치지 않는다"는 Set Packing 문제로 변환. CP-SAT는 배치 탐색 없이 Boolean 선택만 담당. 

"""
pos_candidates[i] = list of (x, y) : 폴리곤 i를 배치할 수 있는 후보 위치
conflict[i][pi][j][pj] = True : 폴리곤 i의 후보 pi와 폴리곤 j의 후보 pj가 충돌
"""

def set_packing_placement(polygons, candidates, conflicts):
    model = cp_model.CpModel()
    n = len(polygons)

    # place[i][p] = 폴리곤 i를 후보 위치 p에 배치
    place = [
        [model.new_bool_var(f"place_{i}_{p}") for p in range(len(candidates[i]))]
        for i in range(n)
    ]

    # 각 폴리곤은 정확히 1개 위치에 배치
    for i in range(n):
        model.add_exactly_one(place[i])

    # 충돌 쌍 금지: place[i][p] + place[j][q] <= 1
    for i in range(n):
        for pi, _ in enumerate(candidates[i]):
            for j in range(i+1, n):
                for pj, _ in enumerate(candidates[j]):
                    if conflicts[i][pi][j][pj]:
                        model.add(place[i][pi] + place[j][pj] <= 1)

    solver = cp_model.CpSolver()
    status = solver.solve(model)
    ...
팁 — Set Packing 스케일 제어

후보 위치 수 |P_i|가 크면 충돌 제약이 O(|P_i|²·n²)으로 폭발한다. BL 포인트(Bottom-Left Normal Form)처럼 구조적 위치만 후보로 남겨 후보 수를 n² 수준으로 줄이는 것이 핵심. (Martello & Toth 1990 "Knapsack Problems" §5)

흔한 함정 요약

함정 1 — 도메인 폭발 (좌표 변수)

x_start = model.new_int_var(0, 10000, ...) 처럼 큰 도메인을 그냥 쓰면 CP-SAT 내부 비트벡터 크기가 폭발한다. 항상 container_size - block_size로 상한을 좁히고, BL 포인트 등 구조적 위치 집합으로 도메인을 사전 필터링하라.

함정 2 — AddNoOverlap2D에 Optional Interval 직접 전달

일부 OR-Tools 버전에서 add_no_overlap_2d에 new_optional_interval_var를 직접 넘기면 "Enforcement literal not supported" 에러가 발생한다. new_optional_fixed_size_interval_var를 사용하거나, OR-Tools 9.9+ 버전을 확인하라.

함정 3 — 정밀도-격자 해상도 트레이드오프 무시

이형 폴리곤을 격자로 이산화할 때 해상도를 높이면 정확도는 올라가지만 도메인 크기가 Δ² 비례로 증가한다. 해상도를 올릴수록 CP-SAT 풀이 시간이 지수적으로 증가할 수 있다. 가능하면 박스 분해 후 분해 박스 수(k)를 줄이는 방향이 더 실용적이다.

함정 4 — 이형 폴리곤 밀도를 CP-SAT로만 달성하려는 시도

OR-Tools 커뮤니티(Discussion #5011, Laurent Perron 언급)에 따르면 "CP-SAT는 기하를 모르며 NoOverlap 제약만 있다 — 회전이 많으면 변형이 폭발한다." 대형 이형 폴리곤 패킹에서는 Bottom-Left 휴리스틱 또는 NFP 기반 배치를 먼저 실행하고, CP-SAT는 타이밍/배정 최적화에만 사용하는 분리 전략이 현실적이다. (OGC 현재 구조: fastfloor가 배치, CP-SAT가 타이밍 = 올바른 분리)

함정 5 — 빈 수를 과도하게 크게 잡기

다중 빈 패킹에서 m=1000 빈을 허용하더라도 성능 저하가 없다는 주장(Kalvelagen 2021)은 특정 인스턴스에서의 관찰이다. 빈 수 변수 b[i]의 도메인을 [0, m-1]로 넓히면 대칭(bin permutation)이 폭발해 탐색 공간이 실질적으로 커질 수 있다. 대칭 제거(bin ordering: 인덱스가 작은 빈을 우선 채움)를 명시적으로 추가하라.

함정 6 — CP-SAT 실현불가 증명의 어려움

CP-SAT는 패킹 문제에서 실현불가(INFEASIBLE) 증명이 특히 느리다. "배치 가능한 해 탐색"에는 강하지만 전체 탐색 공간을 exhaustive하게 증명하는 데는 취약. 시간 제한 내에 해를 못 찾았다고 INFEASIBLE이 아님 — 반드시 상태 코드를 확인하라 (cp_model.INFEASIBLE vs cp_model.UNKNOWN).
