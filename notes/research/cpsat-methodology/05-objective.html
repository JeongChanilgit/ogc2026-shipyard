CP-SAT Methodology · 05

목적함수 & 선형화
max/min/abs/element/곱셈, 다목적 가중합

CP-SAT는 정수 선형 목적식만 직접 지원한다. 비선형 항(최댓값·절댓값·곱셈 등)은 모두 보조 변수 + 등식 제약으로 선형화한다. 이 페이지는 비선형 인코딩 헬퍼 6종, 테이블 제약 2종, 다목적 최적화 패턴(가중합·사전식), 부동소수 가중치의 정수 스케일링 전략을 코드와 함정 중심으로 정리한다.

★ OGC 2026 관련성

OGC 2026 목적함수 min w1·Z1 + w2·Z2 + w3·Z3는 세 개의 이질적 항으로 구성된다. Z1 = Σ tardiness → 블록마다 max(0, exit − due)를 AddMaxEquality로 인코딩. Z2 = max workload imbalance (베이별 부하의 최댓값 최소화) → 보조 변수에 AddMaxEquality 후 Minimize. Z3 = Σ(S_max − S_chosen) 선호편차 → 선형 합산. 가중치 w1이 667 ~ 29,600으로 자릿수가 크게 다르므로 정수 스케일 × 1,000 후 LinearExpr.weighted_sum을 weight-adaptive하게 쓰는 것이 핵심.

1. 기초: Minimize / Maximize

CP-SAT의 목적식은 하나의 선형 표현식이어야 한다. model.minimize(expr) 또는 model.maximize(expr)를 한 번만 호출한다. 나중에 호출하면 이전 목적식을 덮어쓴다.

from ortools.sat.python import cp_model

model = cp_model.CpModel()
x = model.new_int_var(0, 100, "x")
y = model.new_int_var(0, 100, "y")

# 단순 선형 목적
model.minimize(3 * x + 7 * y)

# 가중합 헬퍼 — 변수·가중치 리스트
xs = [model.new_int_var(0, 50, f"x{i}") for i in range(5)]
weights = [10, 20, 5, 15, 8]
model.minimize(cp_model.LinearExpr.weighted_sum(xs, weights))
Tip — LinearExpr.weighted_sum

리스트 내포보다 LinearExpr.weighted_sum(vars, coeffs)가 가독성·안정성 모두 낫다. 가중치가 부동소수점이라면 먼저 정수로 스케일 변환(§6 참조)하고 넘겨야 한다.

2. 비선형 인코딩 헬퍼 6종

비선형 항은 보조 변수 선언 → 등식 제약 추가 → 목적식에 보조 변수 포함 패턴으로 처리한다. CP-SAT는 이 보조 변수의 도메인을 전파 시 활용하므로, 도메인 상한을 꽉 잡아야 전파가 강해진다.

2.1 AddMaxEquality / AddMinEquality

model.add_max_equality(target, exprs) — target == max(exprs)
model.add_min_equality(target, exprs) — target == min(exprs)

# ── Makespan(최대 완료시각) 최소화 ──
end_times = [model.new_int_var(0, horizon, f"end_{i}") for i in range(n_tasks)]
makespan = model.new_int_var(0, horizon, "makespan")
model.add_max_equality(makespan, end_times)
model.minimize(makespan)

# ── 워크로드 불균형(베이별 부하 최댓값−최솟값) 최소화 ──
loads = [model.new_int_var(0, max_load, f"load_{j}") for j in range(n_bays)]
max_load_var = model.new_int_var(0, max_load, "max_load")
min_load_var = model.new_int_var(0, max_load, "min_load")
model.add_max_equality(max_load_var, loads)
model.add_min_equality(min_load_var, loads)
model.minimize(max_load_var - min_load_var)
Tip — 순수 minimax는 선형 불등식이 더 빠를 수 있다

최댓값을 최소화만 할 경우 add_max_equality 대신 model.add(max_var >= load_j)를 모든 j에 적용하고 minimize(max_var)를 쓰면 전파 회로가 단순해져 종종 더 빠르다. 반대로 최댓값을 제약 좌변에 사용하거나 다른 목적항과 결합할 때는 add_max_equality가 필수다.

함정 — 도메인 상한 미설정

model.new_int_var(0, cp_model.INT_MAX, "max_var")처럼 상한을 INT_MAX로 두면 CP-SAT가 bound를 추론하기 어렵고 전파가 크게 약해진다. 반드시 horizon이나 sum(all_processing_times) 같은 의미 있는 상한을 쓴다.

2.2 AddAbsEquality

model.add_abs_equality(target, expr) — target == |expr|
편차·잔차·이진 분류 비용 등에 활용한다.

# ── 목표 편성 수 대비 절댓값 편차 최소화 ──
target_slots = 8
total_slots = model.new_int_var(0, max_slots, "total")
deviation_raw = model.new_int_var(-max_slots, max_slots, "dev_raw")
model.add(deviation_raw == total_slots - target_slots)

abs_dev = model.new_int_var(0, max_slots, "abs_dev")
model.add_abs_equality(abs_dev, deviation_raw)
model.minimize(abs_dev)

# ── Σ|x_i − median| 형태 (다수 변수의 MAD) ──
diffs = []
for i in range(n):
    raw = model.new_int_var(-big, big, f"raw_{i}")
    model.add(raw == x[i] - median_var)
    ab = model.new_int_var(0, big, f"ab_{i}")
    model.add_abs_equality(ab, raw)
    diffs.append(ab)
model.minimize(sum(diffs))

2.3 AddMultiplicationEquality

model.add_multiplication_equality(target, exprs) — target == exprs[0] * exprs[1] * …

# ── 이진 변수 × 연속 변수 (선택적 비용) ──
selected = model.new_bool_var("selected")
cost = model.new_int_var(0, 1000, "cost_val")
active_cost = model.new_int_var(0, 1000, "active_cost")
model.add_multiplication_equality(active_cost, [selected, cost])

# 단, 이진×연속은 OnlyEnforceIf 패턴이 훨씬 강력한 전파를 줌:
active_cost_alt = model.new_int_var(0, 1000, "active_cost_alt")
model.add(active_cost_alt == cost).only_enforce_if(selected)
model.add(active_cost_alt == 0).only_enforce_if(selected.negated())
함정 — AddMultiplicationEquality의 도메인 폭발과 약한 전파

두 변수 a∈[0,100], b∈[0,100]의 곱은 도메인 크기가 10,001이 된다. CP-SAT는 이 제약에 대해 전파가 약하고, 탐색 시간이 선형 모델 대비 수배 이상 늘어날 수 있다. 이진×연속은 only_enforce_if로, 정수×정수는 테이블/열거로 대체하는 것이 원칙이다. 세 개 이상의 변수 곱은 구버전에서 지원하지 않는다 (≥v9.4 에서는 배열 지원).

2.4 AddElement (인덱스 기반 조회)

model.add_element(index, variables, target) — target == variables[index]
변수 인덱스로 다른 변수를 조회하거나, 비선형 함수를 룩업 테이블로 대체한다.

# ── 비선형 함수를 룩업 테이블로 ──
# f(x) = x^2 을 정수 룩업으로 처리
x = model.new_int_var(0, 20, "x")
table = [i * i for i in range(21)]          # [0, 1, 4, 9, … 400]
f_x = model.new_int_var(0, 400, "x_sq")
model.add_element(x, table, f_x)           # f_x == table[x]

# ── 배정 결과에 따른 가중치 조회 ──
bay_assigned = model.new_int_var(0, n_bays - 1, "bay")
preference_weights = [10, 25, 15, 30, 5]   # 베이별 선호도
pref_score = model.new_int_var(0, max(preference_weights), "pref")
model.add_element(bay_assigned, preference_weights, pref_score)
model.maximize(pref_score)
Tip — AddElement는 비선형 블랙박스 함수의 CP-SAT 내 최선 대안

도메인이 작고 함수값이 미리 계산 가능하면 add_element로 O(1) 조회가 가능하다. 단, 도메인이 크면 테이블 크기 자체가 메모리를 잡아먹으므로 적정 도메인 범위(≤10,000)를 유지한다.

2.5 AddDivisionEquality / AddModuloEquality

# target == a // b  (정수 나눗셈, b는 상수여야 전파 강함)
quotient = model.new_int_var(0, 100, "q")
model.add_division_equality(quotient, a_var, b_const)

# target == a % m
remainder = model.new_int_var(0, m - 1, "rem")
model.add_modulo_equality(remainder, a_var, m)
함정 — 분모가 변수일 때 전파 극도 약화

add_division_equality(q, a, b)에서 b가 변수이면 CP-SAT는 케이스 열거에 의존하며 매우 느려진다. 가능하면 b를 상수로 고정하거나 add_element 룩업으로 대체한다.

3. 테이블 제약: AddAllowedAssignments / AddForbiddenAssignments

여러 변수의 결합(joint) 값 집합을 명시적으로 허용하거나 금지한다. 조건부 비용 행렬, 복잡한 선호 규칙, 이산 페어링 패턴에 유용하다.

# ── 허용 배정 ──
# (block_type, bay_type) 페어의 허용 목록
block_type = model.new_int_var(0, 3, "bt")
bay_type   = model.new_int_var(0, 2, "bayt")
allowed = [(0,0),(0,1),(1,0),(1,2),(2,1),(3,2)]
model.add_allowed_assignments([block_type, bay_type], allowed)

# ── 금지 배정 ──
forbidden = [(0,2),(1,1),(2,0),(3,0),(3,1)]
model.add_forbidden_assignments([block_type, bay_type], forbidden)

# ── 조건부 비용: (레이어, 방향) → 추가 비용 룩업 ──
layer   = model.new_int_var(0, 3, "layer")
orient  = model.new_int_var(0, 1, "orient")
penalty = model.new_int_var(0, 100, "penalty")
cost_table = [(l, o, (l+1)*(o*50+10)) for l in range(4) for o in range(2)]
model.add_allowed_assignments([layer, orient, penalty], cost_table)
Tip — 튜플 크기 불일치는 ValueError

add_allowed_assignments(vars, tuples)에서 각 튜플의 길이가 vars 리스트 길이와 다르면 즉시 ValueError가 발생한다. 비용 변수를 함께 넣을 경우 튜플 길이를 맞춰야 한다.

4. 목적식 조합 패턴

4.1 Z1 — 지연합 (Tardiness)

tardiness_i = max(0, exit_i − due_i)는 CP-SAT에서 아래 두 방법으로 인코딩한다.

# 방법 A: add_max_equality 사용
tardiness = []
for i in range(n_blocks):
    t = model.new_int_var(0, horizon, f"tard_{i}")
    model.add_max_equality(t, [0, exit_time[i] - due_date[i]])
    tardiness.append(t)
z1 = sum(tardiness)

# 방법 B: 불등식으로 하한만 설정 (전파 동등, 종종 더 빠름)
tardiness_b = []
for i in range(n_blocks):
    t = model.new_int_var(0, horizon, f"tard_b_{i}")
    model.add(t >= exit_time[i] - due_date[i])
    model.add(t >= 0)
    tardiness_b.append(t)
# 최소화 목적이면 방법 B의 t가 자동으로 tight해진다
Tip — 최소화 시 방법 B가 선호

목적이 Σtardiness를 최소화할 때는 하한 불등식만 설정해도 됩니다. solver가 z1을 낮추려면 t를 최대한 0에 가깝게 유지하려 하므로 자동으로 tight. add_max_equality는 양방향 등식이라 불필요한 전파 단계가 생긴다.

4.2 Z2 — 워크로드 불균형 (minimax)

# 베이별 총 점유 면적을 load_j에 집계
load_vars = []
for j in range(n_bays):
    lv = model.new_int_var(0, max_area, f"load_{j}")
    model.add(lv == sum(area[i] * assign[i][j] for i in range(n_blocks)))
    load_vars.append(lv)

# Z2 = max_j(u_j * load_j) — 베이 가중 u_j 반영
weighted_loads = []
for j in range(n_bays):
    wl = model.new_int_var(0, u[j] * max_area, f"wload_{j}")
    # u_j가 정수라면 직접 곱셈 가능
    model.add(wl == u[j] * load_vars[j])
    weighted_loads.append(wl)

z2_var = model.new_int_var(0, max(u) * max_area, "z2")
model.add_max_equality(z2_var, weighted_loads)
# 또는 선형 하한:
for wl in weighted_loads:
    model.add(z2_var >= wl)

4.3 Z3 — 선호편차 (가중 선형합)

# S_chosen: 블록 i가 배정된 베이 j의 선호점수 (AddElement 활용)
pref_score = []
for i in range(n_blocks):
    bay_i = model.new_int_var(0, n_bays-1, f"bay_{i}")
    ps = model.new_int_var(0, S_MAX, f"pref_{i}")
    model.add_element(bay_i, S_table[i], ps)   # S_table[i][j] = S_ij
    pref_score.append(ps)

# Z3 = Σ(S_max_i − pref_score_i)
z3 = sum(S_max[i] - pref_score[i] for i in range(n_blocks))

4.4 가중합 통합 목적식

# w1, w2, w3 가 부동소수점일 경우 정수 스케일링 (§6 참조)
SCALE = 1000
w1_int = round(w1 * SCALE)
w2_int = round(w2 * SCALE)
w3_int = round(w3 * SCALE)

objective = cp_model.LinearExpr.weighted_sum(
    [z1_var, z2_var, z3_var],
    [w1_int, w2_int, w3_int]
)
model.minimize(objective)

5. 다목적 최적화 패턴

5.1 가중합 (Weighted Sum) — 단일 Minimize

가장 단순하고 빠른 방법. 모든 목적항을 공통 스케일로 정수화한 뒤 하나의 minimize로 묶는다. 장점: 단일 solve 패스, Pareto front 위의 한 점을 찾음. 단점: 가중치 선택이 결과를 크게 좌우함, 자릿수 차이가 크면 한 항이 지배. 

model.minimize(w1_int * z1_var + w2_int * z2_var + w3_int * z3_var)

5.2 사전식 최적화 (Lexicographic / 2-Phase)

우선순위가 높은 목적을 먼저 최적화하고, 그 값을 고정한 뒤 다음 목적을 최적화한다. OGC처럼 −1 회피(실현가능성)가 1순위일 때 유용하다. 

from ortools.sat.python import cp_model
import math

solver = cp_model.CpSolver()
solver.parameters.max_time_in_seconds = time_budget_1

# 1단계: Z1(지연합) 최소화
model.minimize(z1_var)
status = solver.solve(model)
best_z1 = int(solver.objective_value)

# 2단계: Z1 값 고정 후 Z2+Z3 최소화
model.add(z1_var <= best_z1)          # 엄격 고정 대신 허용 오차 줄 수도 있음
model.minimize(w2_int * z2_var + w3_int * z3_var)
solver.parameters.max_time_in_seconds = time_budget_2
status = solver.solve(model)
Tip — 허용 오차(ε-relaxation) 활용

1단계 최적값을 엄격히 고정하면 2단계에서 실현가능 해가 없어지거나 검색 공간이 지나치게 좁아질 수 있다. model.add(z1_var <= best_z1 + epsilon)처럼 ε만큼의 여유를 주면 2단계에서 훨씬 좋은 Z2/Z3 해를 찾을 수 있다. 

# 고급 패턴: 전 단계 해를 힌트로 활용 (warm start)
class MultiObjSolver:
    def __init__(self, model, solver):
        self.model = model
        self.solver = solver
        self._obj_var = None

    def set_objective(self, expr):
        self._obj_var = expr
        self.model.minimize(expr)

    def solve(self, time_limit=60.0):
        self.solver.parameters.max_time_in_seconds = time_limit
        return self.solver.solve(self.model)

    def fix_and_hint(self, ratio=1.0):
        """현재 최적값 고정 + 현재 해를 다음 단계의 힌트로 등록"""
        opt_val = int(math.ceil(self.solver.objective_value * ratio))
        self.model.add(self._obj_var <= opt_val)
        # 힌트 등록 (OR-Tools v9.x 이상)
        for v in self.model.get_bool_vars_from_constraint_indices([]):
            self.model.add_hint(v, self.solver.value(v))

5.3 Pareto Front 탐색

가중치 벡터를 달리 하며 여러 번 풀어 Pareto front를 근사한다. 실전에서는 2~5개 가중치 조합이면 의사결정에 충분한 경우가 많다. 

results = []
for alpha in [0.0, 0.25, 0.5, 0.75, 1.0]:
    model2 = model.clone() if hasattr(model, 'clone') else copy_model(model)
    model2.minimize(round(alpha * 1000) * z1_var +
                    round((1-alpha) * 1000) * z2_var)
    s = cp_model.CpSolver()
    s.parameters.max_time_in_seconds = 30
    s.solve(model2)
    results.append((alpha, s.value(z1_var), s.value(z2_var)))

6. 부동소수 가중치의 정수 스케일링

CP-SAT는 목적함수 계수를 64비트 정수로 다룬다. 부동소수 가중치(예: w1=667.3)는 반드시 정수화해야 한다.

6.1 단순 비례 스케일링

def scale_weights(weights, precision=1000):
    """부동소수 가중치 → 정수. precision배 후 반올림."""
    return [round(w * precision) for w in weights]

# 예: OGC 가중치 (실 인스턴스 범위 667 ~ 29600)
raw_w = [667.5, 29600.0, 133.0]
int_w = scale_weights(raw_w, precision=1000)
# → [667500, 29600000, 133000]
# ⚠ 최대 계수 29.6M × 최대 변수값 5M ≈ 1.48e14 → int64 범위(9.2e18) 안에 있음
함정 — int64 오버플로우

CP-SAT 목적식 계수 × 변수 최대값이 2⁶³ ≈ 9.2 × 10¹⁸을 넘으면 INVALID_MODEL("Potential integer overflow in constraint")이 발생한다. 스케일 × max(var_domain)가 9.2e18을 넘지 않도록 precision 값을 조정한다. 검증: assert max(int_w) * max_var_bound < 9e18

6.2 최소공배수(LCM) 방식 — 소수점 정밀도 보존

from math import gcd
from fractions import Fraction

def exact_scale(weights):
    """분수로 표현 후 분모 LCM을 구해 모두 정수화"""
    fracs = [Fraction(w).limit_denominator(10000) for w in weights]
    lcm_den = 1
    for f in fracs:
        lcm_den = lcm_den * f.denominator // gcd(lcm_den, f.denominator)
    return [int(f * lcm_den) for f in fracs], lcm_den

int_w, scale = exact_scale([0.5, 0.333, 1.0])
# → ([3, 2, 6], 6)  즉 0.5→3, 0.333→2, 1.0→6 (÷6 하면 원래 비율 복원)

8. OGC 2026 통합 예제 (Z1+Z2+Z3 최소화)

OGC 2026 — 실전 목적함수 조립 패턴

아래 코드는 OGC 2026 목적함수 w1·Z1 + w2·Z2 + w3·Z3의 CP-SAT 조립 전체를 보여준다. weight-adaptive 처리와 int64 안전성 검증이 포함된다. 

from ortools.sat.python import cp_model
import math

def build_objective(model, prob_info,
                    exit_time, bay_assign, pref_score):
    """
    exit_time[i]   : IntVar — 블록 i의 퇴출 시각
    bay_assign[i]  : IntVar — 블록 i의 베이 인덱스
    pref_score[i]  : IntVar — 선호 점수 (AddElement로 설정됨)
    """
    w1 = prob_info["w1"]
    w2 = prob_info["w2"]
    w3 = prob_info["w3"]
    due = prob_info["due_dates"]        # list[int]
    bay_weight = prob_info["bay_u"]     # u_j 베이 가중치
    horizon = prob_info["horizon"]
    n_blocks = len(exit_time)
    n_bays = len(bay_weight)

    # ── 1. 정수 스케일 계산 (overflow 안전) ──
    SCALE = 1000
    w1i, w2i, w3i = round(w1*SCALE), round(w2*SCALE), round(w3*SCALE)
    max_z1 = n_blocks * horizon
    max_z2 = max(bay_weight) * max(sum(b['area'] for b in prob_info['blocks']), 1)
    max_z3 = sum(prob_info['S_max'])
    assert max(w1i*max_z1, w2i*max_z2, w3i*max_z3) < 9e18, "int64 overflow 위험"

    # ── 2. Z1: 지연합 (방법 B — 하한 불등식) ──
    tardiness = []
    for i in range(n_blocks):
        t = model.new_int_var(0, horizon, f"tard_{i}")
        model.add(t >= exit_time[i] - due[i])
        model.add(t >= 0)
        tardiness.append(t)
    z1_var = model.new_int_var(0, max_z1, "z1")
    model.add(z1_var == sum(tardiness))

    # ── 3. Z2: 베이별 가중 부하의 최댓값 ──
    block_areas = [prob_info['blocks'][i]['area'] for i in range(n_blocks)]
    wload = []
    for j in range(n_bays):
        raw_load = model.new_int_var(0, sum(block_areas), f"load_{j}")
        # 블록 i가 베이 j에 배정되면 area[i] 기여
        assign_ij = [model.new_bool_var(f"aij_{i}_{j}") for i in range(n_blocks)]
        for i in range(n_blocks):
            model.add(assign_ij[i] == 1).only_enforce_if(
                bay_assign[i] == j)   # 주의: 실제로는 별도 bool로 채널링 필요
        model.add(raw_load == sum(
            block_areas[i] * assign_ij[i] for i in range(n_blocks)))
        wl = model.new_int_var(0, bay_weight[j] * sum(block_areas), f"wload_{j}")
        model.add(wl == bay_weight[j] * raw_load)
        wload.append(wl)
    z2_var = model.new_int_var(0, max_z2, "z2")
    for wl in wload:
        model.add(z2_var >= wl)       # minimax: 하한 불등식 패턴

    # ── 4. Z3: 선호편차 합 ──
    S_max_total = sum(prob_info['S_max'])
    z3_var = model.new_int_var(0, max_z3, "z3")
    model.add(z3_var == sum(
        prob_info['S_max'][i] - pref_score[i] for i in range(n_blocks)))

    # ── 5. 통합 목적식 ──
    model.minimize(
        cp_model.LinearExpr.weighted_sum(
            [z1_var, z2_var, z3_var],
            [w1i,    w2i,    w3i]
        )
    )
    return z1_var, z2_var, z3_var

9. 흔한 함정 요약

함정 현상 해결책
보조 변수 도메인 상한 = INT_MAX 전파 약화, 탐색 느려짐 의미 있는 상한(horizon, sum(areas)) 설정
add_max_equality에 표현식 직접 전달 TypeError (변수만 허용) 중간 변수 만들고 model.add()로 표현식 바인딩
AddMultiplicationEquality 남용 도메인 폭발, 전파 극도 약화 이진×연속은 only_enforce_if, 정수×정수는 AddElement
부동소수 가중치를 정수화 않고 사용 INVALID_MODEL 또는 자동 반올림 오류 SCALE × round() 후 int64 overflow 검증
사전식 1단계 값 엄격 고정 2단계 infeasible 또는 Pareto 탐색 불가 ε-relaxation: z1_var ≤ best_z1 + ε
계수 × 변수상한 > 9.2e18 int64 오버플로우 → INVALID_MODEL SCALE 줄이거나 변수 도메인 분할
Minimize 여러 번 호출 마지막 호출만 적용, 이전 목적 무시 목적식을 합산한 뒤 한 번만 호출
AddAllowedAssignments 튜플 길이 불일치 ValueError 즉시 발생 변수 리스트와 튜플 길이 assert로 검증
