2. 근본 원인 — 내가 리셋에서 잃은 기술

옛 솔버 = 분리(decouple) ✓

① 레이아웃 먼저: 크레인-안전 greedy BL로 위치 고정 (fastfloor._fixed_time_decode)

② 시간은 나중: 고정 레이아웃 위 CP-SAT 타이밍 오라클 (_cpsat_bay_timing_verified) → 위치 고정이라 충돌이 시간-독립 불린 → 깨끗한 1-D 스케줄링 → 최적 해결

⇒ z1=0 on 19/20

내 box-decomp = 동시(joint) ✗

위치+시간을 한 모델에서 동시 탐색 (쌍별 6-리터럴 분리)

→ 40+블록 베이에서 조합폭발 → incumbent만 찾음

⇒ z1이 100~190에서 바닥 (congested 인스턴스)

cumulative·4워커·z1zero·targeted-spill 전부 시도 → CP-SAT 천장 못 넘음

3. 현재 활성 솔버 — 하이브리드

src/myalgorithm.py algorithm() = best-of(_legacy_algorithm 옛 솔버, boxsolver.algorithm box-decomp). 게이트 OGC_HYBRID(기본 ON).

구성: box-decomp가 덜 혼잡한 prob_3/4/18에서 z1=0을 더 낮은 z3로 실현(옛 솔버가 과다-spill하는 곳) → 거기선 box 채택. 혼잡한 나머지는 옛 솔버 채택. best-of라 인스턴스별 무회귀, box 후보는 try/except로 감싸 −1 추가위험 없음.
예산: legacy 는 ~140-300s에 plateau(검증됨) ⇒ box용 예산 reserve 해도 서버 TL에선 회귀 0(로컬 prob_14만 −2,918).
검증: full set1 gate = 1,312,961 (옛 1.39M 대비 −72,818; prob_3/4/18 개선, prob_14 소폭 회귀).

6. 다음 — 결정 필요

<1M은 검증 가능한 모든 레버 소진 후 도달 불가로 확인 (cppack 포함 8개 레버 측정; 경쟁자 패킹 밀도 = 반증된 폴리곤-네스터 레버). 남은 선택지:
  • retarget — 1.31M 확정 + 현실적 목표(예: <1.3M, 이미 달성). 6.9× 회복을 락인. 권고
  • set2 보강 — 옛 솔버 set2 취약(타임아웃 → −1). 실제 ALL40 점수엔 set1 0.3M보다 이게 더 위협. 권고
  • gurobi — 서버 전용 joint-MIP 도박. 멀티시간, 구조만 로컬검증, gated(−1 무위험), 낮은 확률(CP-SAT가 패킹엔 Gurobi보다 보통 우위; box-packer 이미 반증).
권고: retarget + set2 보강. cppack도 측정 완료 → 무효. <1M엔 경쟁자급 패킹 밀도 돌파(미검증 Gurobi 도박)만 남음.
