2. 시퀀스별 — 인사이트 · CP-SAT 재모델링 · 벤더스 컷

① greedy baseline floor Greedy

~65s · legacy 내부

역할: 크레인-aware Bottom-Left로 초기 실현가능 레이아웃 생성 (배정+위치).

인사이트: 시간 최대 소비자인데 obj 기여 ≈ 0. set2에선 box/gassign이 늘 이겨 출력이 통째로 폐기됨.

CP-SAT 재모델링: 가능·고가치 — 이건 사실상 gassign의 _cpsat_assignment(배정) + per-bay 패킹이 이미 하는 일이다. greedy floor를 적출하고 그 시간을 CP-SAT 후보에 넘기면 된다(사용자 방향과 일치). 린 레거시 실험이 이 경로(_cpsat_assignment → fixed-time decode → 타이밍오라클).

벤더스 컷: floor 자체는 아님. 대체재(gassign)가 LBBD 마스터가 된다.

② cum_level / post-search Greedy

~60s · legacy 내부

역할: 그리디 해 위 국소 재배치·이동 탐색.

인사이트: cum_level −0.4%, single_move −8% — set2 저가치. 시간 대비 미미.

CP-SAT 재모델링: 불필요 — CP-SAT 배정/타이밍이 이미 이 영역을 더 잘 푼다. KILL 후보

벤더스 컷: N/A.

③ cpsat_timing — 타이밍 오라클 CP-SAT Benders 서브문제

~3.5s · ★최고 ROI

역할: 위치를 고정한 상태에서 각 블록의 ENTRY/EXIT 시각을 최적화. 베이별 1-D disjunctive(크레인 j≥k 직렬화) tardiness를 CP-SAT로 최적까지.

인사이트: 3.5초에 −49%(prob_26 426M→218M). 위치·시간을 분리(decouple)한 덕에 작고 빠른 문제로 떨어진다 — 동시에 풀면 폭발.

CP-SAT 개선: 이미 CP-SAT·거의 최적. 잔여 레버 = warm-start(직전 해 hint)로 시간 더 단축, 멀티-베이 결합(단 결합 약함 → EV 낮음). 대체로 완성.

벤더스 컷: 이것이 바로 벤더스 서브문제(오라클)다. 현재는 타이밍만 풀고 끝나지만, 여기서 "이 배정으론 tardy를 N개 이하로 못 만든다"는 컷(no-good / tardy-cardinality)을 배정 마스터로 되돌리면 realize 갭이 닫힌다. 고가치 미구현 레버.

④ box_candidate — box-decomp CP-SAT

~74s

역할: 박스 분해 기반 전결정 CP-SAT 해. 패킹-heavy 인스턴스의 주력 승자(prob_30 255M→13M, prob_38 145M→85M).

인사이트: 위치→시간 순으로 분해. 패킹 밀도가 본질 한계(density wall) — prob_38의 +16.6M 잔여가 여기서 막힘.

CP-SAT 재모델링: 이미 CP-SAT. 진짜 레버 = 밀도: semi-discrete BLF / 침투맵(penetration map)으로 후보 배치를 더 촘촘히(리서치 §갈래1·미구현).

벤더스 컷: 이미 LBBD 풍(위치 마스터 ↔ 시간 서브). z3-aware 마스터 컷 추가 여지.

⑤ gassign_candidate CP-SAT LBBD 정석

~68s · 굶주림

역할: z1-aware CP-SAT 배정 마스터(T2 누적 area-time) + per-bay 디코드 오라클 + no-good 컷(T6 LBBD).

인사이트: 경쟁력 있으나 순차 하이브리드에서 슬라이스(0.27T≈68s)에 굶주림. depgroup 레버로 z3 회복(base-first race, Pareto-safe).

CP-SAT 개선: 마스터에 시간 더(병렬 C1은 실패) → greedy floor 적출분을 직렬로 몰아주기가 정답. depgroup 기본 ON.

벤더스 컷: 여기가 이 문제의 정석 LBBD다. 마스터(완화 배정) ↔ per-bay 디코드 오라클 ↔ no-good 컷. 잔여 갭은 마스터가 z3-과스필을 못 봄 — z3-spill 컷(C4)을 추가하면 경쟁자와의 z3 갭(prob_39 우리 9610 vs 경쟁자 59) 직격.

⑥ perbay_candidate CP-SAT

~19s

역할: best 후보의 개별 베이를 per-bay CP-SAT 패킹으로 재최적화(post-refine).

인사이트: 작은 추가 이득(prob_38 84.9→81M, −4.6%). additive·gated·never−1.

CP-SAT 재모델링: 이미 CP-SAT. 베이별 NoOverlap+크레인 조인트. 밀도 한계는 box와 동일.

벤더스 컷: per-bay = 서브문제 레벨. 마스터로 컷 환류 가능(현재는 단방향 refine).

3. 벤더스 컷(Benders cut) — 이 문제에 어떻게 적용되나

왜 분해하나: 배정·위치·방향·시각을 동시에 풀면 NP-hard 3중결합이 폭발한다. 그래서 둘로 쪼갠다.

  • 마스터(master): "어느 블록을 어느 베이에" — 완화된(relaxed) CP-SAT 배정. 기하·크레인을 area-time 근사로만 봄 → 빠름.
  • 서브문제(subproblem) = 오라클: 마스터가 준 배정을 받아 진짜 per-bay 패킹+크레인+타이밍을 푼다(타이밍 오라클 ③). 실제 tardiness가 나옴.

벤더스 컷 = 서브 → 마스터 피드백. 서브가 "이 배정은 tardy ≥ N개라 나쁘다(또는 실현불가)"를 알아내면, 그 정보를 제약(컷)으로 마스터에 되돌린다: "이 베이에 이 블록 조합 → 금지/페널티". 마스터는 그 컷을 안고 다시 배정 → 더 나은 후보 → 다시 서브 검증 … 수렴할 때까지 반복.

현재 상태: gassign(⑤)이 no-good 컷 LBBD를 이미 돌린다. 미구현 고가치 레버 2개: (a) 타이밍 오라클(③)의 tardy-cardinality 컷을 배정 마스터로 환류 → realize 갭(z3는 낮은데 z1=0으로 안 떨어지는 문제) 해소. (b) z3-spill 컷(C4) → 마스터의 과스필 억제, 경쟁자와의 z3 갭 직격.

4. 결론 · 다음 방향

  1. C1 병렬은 폐기. 코어 분할이 큰 인스턴스를 퇴화시킴 — banked best-of가 더 낫다(prob_38 +29M, prob_39 +5.6M).
  2. 시간 레버 = 병렬이 아니라 적출. greedy floor/post-search(~125s, 45% wall, set2 폐기)를 줄여 그 예산을 box/gassign에 직렬로 몰아준다.
  3. 점수 레버 = 벤더스 컷 강화. ③ 타이밍오라클의 tardy 컷 환류 + ⑤ gassign의 z3-spill 컷(C4). 둘 다 경쟁자와의 잔여 갭(z3 + prob_38 z1-wall)을 직접 공격.
  4. prob_38이 전부. +16.6M = 전체 갭(+13.3M) 초과. 이건 패킹 density wall(box 한계) — 밀도 레버(semi-discrete BLF/침투맵, 미구현)가 유일한 진짜 추월로.

제 1순위 추천: ③ 타이밍 오라클의 tardy-cardinality 컷을 gassign 마스터로 환류 — 이미 있는 오라클을 재활용하므로 구현 싸고, realize 갭(z3 낮은데 z1 안 떨어지는)을 정조준. CP-SAT/벤더스 적극 활용의 정석.
