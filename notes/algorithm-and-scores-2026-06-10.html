한 줄. EDD 그리디 floor → CP-SAT/로컬서치 후처리 → full-objective gate 의 3단 파이프라인. 핵심 설계는 (1) 짧은 평가시간에 z1 폭발을 막는 adaptive raster floor 게이트 와 (2) 검증된 floor보다 나빠지지 않는 objective-safe gate(−1 원천 차단). 전 20개 인스턴스 100/300/1000초 모두 feasible · −1 0건, 시간을 주면 총 obj가 −43% 내려간다.

1 목적함수

min   w1·Z1  +  w2·Z2  +  w3·Z3
Z1 — 지연(tardiness)
w1 ≈ 10,000 ~ 29,000 (지배적)
Σ max(0, EXIT − due). 크레인 수직접근(j≥k)으로 블록이 직렬화되면 EXIT가 밀려 발생. 가중치가 압도적이라 −1 다음으로 1순위.
Z2 — 작업부하 불균형
w2 ≈ 4 ~ 10 (작음)
베이 가중 부하의 (max − min). 베이 배정만의 함수. 가중치가 작아 obj 기여도 미미.
Z3 — 선호도 이탈
w3 ≈ 125 ~ 200
Σ (Smax − S선택베이). 베이 배정만의 함수(위치·시간 무관). z1=0인 인스턴스에선 obj의 84~99%를 차지하는 숨은 지배자.

결정변수(블록당 동시): 베이 j · 위치 (x,y) · 방향 o · ENTRY 시각 · EXIT 시각. 3개 NP-hard(2D 비정형 패킹 + 단일머신 tardiness + 배정)가 결합.

2 파이프라인 (floor → 후처리 → gate)

A
FLOOR — EDD + Best-Fit 그리디 + 리페어 z1 기반
블록을 EDD(마감 빠른 순)로 정렬, 각 블록을 (베이·방향·위치·시각) 후보 중 _placement_score(w1·tard + w2·load + w3·pref) 최소로 배치 → 위반은 후처리 리페어. 검증된 feasible 해를 보장(이게 −1 방지의 바닥).
▼  adaptive 게이트: 1.2e-3·n² > 0.4·T 이면(짧은 tl·큰 인스턴스) → raster floor + pos_k=3, 아니면 default
B
cum_level — 베이별 CP-SAT 재디코드 z1
베이별로 위치·시각을 다시 풀어 tardiness를 낮춤. 후처리 예산의 ~70% 사용(가장 무거운 z1 레버).
C
bbox_pack / cpsat_timing — CP-SAT 위치·타이밍 z1
시간 겹침 ⟹ footprint 공간분리(크레인-safe)로 직렬화를 공간으로 펼쳐 tardiness 추가 절감.
D
crossbay_relocate / Front B — 베이 재배정 z2·z3
z1=0이면 블록을 선호 베이로 relocate/swap(_assignment_proxy로 랭크)해 z3(선호도) 절감. z3 최적화의 유일 능동 레버. 후처리 끝에서 남은 예산만 사용.
E
seeds_decode — 대안 배정 디코드 탐색
선호도-우선/부하-균형/CP-SAT(z2+z3 최소)/floor 배정을 seed로 재디코드해 더 나은 배정 탐색.
▼
✓
GATE — consider() full-objective 채택 objective-safe
모든 후보를 전체 목적함수로 비교해 best만 유지. 검증된 floor를 절대 밑돌지 않음 → −1(infeasible/timeout)·악화 원천 차단. 모든 실험 노브는 default OFF라 기본 동작 무회귀.

3 핵심 설계 결정

채택 Adaptive raster floor 게이트

  • 짧은 tl·큰 인스턴스에선 default 그리디 floor가 느려 z1이 폭발(예: prob_20 35,795)하고 −1 위험.
  • 크레인 충돌검사를 Shapely 대신 폴리곤-래스터(정수셀 보수적 superset) 로 바꿔 빠르게 → 넓은 위치탐색(pos_k=3) 가능 → dense·feasible floor로 z1 제압.
  • 긴 tl엔 발동 안 함(max est=108 < 0.4·300=120) → default floor 그대로(무회귀). = 짧은-tl 보험.
  • 효과: tl=100서 catastrophe(obj 6.5M~46M) → 정상(208K~669K).

특성화된 한계 (조사로 확정)

  • z1: 시간 주면 해결(긴 tl서 19/20 z1≤2). 평가서버 긴 예산이면 거의 0.
  • z3: z1↔z3 Pareto에 막힘. 블록을 선호 베이로 몰면 과부하→z1 20~180배 폭발. 현 z3는 "z1=0 유지의 대가". 짧은 tl도 동일(raster 과밀).
  • 변동: CP-SAT 4-worker wall-clock 비결정성으로 ±15~27% run-to-run 변동(잔존 핵심 요인).
  • prob_13: 긴 tl서 후처리가 더 좋은 해(z1=1)를 버리고 z1=10에 수렴(비단조) → best-obj 유지 fix시 ~26% 개선 여지(차기 1순위).

5 요약 & 다음

  • 성숙도: z1 해결(시간), z3 Pareto-floor, z2 가중치 미미, 전 구간 −1 0건. 시간 확장성 양호(−43%).
  • 차기 1순위: prob_13류 비단조 후처리 — best-full-obj 유지(궤적 중 더 좋은 해 보존)로 prob_13 ~26% 개선, 일반 fix 가능성.
  • 막다른 길 CP-SAT 전역 z3 재배정(packing-blocked) · Front B 튜닝/best-of-N(노이즈) · 짧은-tl z3(raster z1-안전 대가) · best-of-two floor(감당·예측 불가).
