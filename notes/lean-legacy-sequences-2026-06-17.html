① 배정 마스터 — _cpsat_assignment :1615

CP-SATz1-blindnum_search_workers=4, max_time=_ll_ab

역할: 모든 블록을 베이에 배정해 z2(workload 불균형) + z3(선호 이탈)의 가중합 최소화.

입력
prob_info, bays, feasible_bays, bay_u, time_budget(=_ll_ab), hint
출력
assign: list[int] (블록→베이), 실패 시 None
결정 변수
x[b,j] BoolVar — 블록 b를 베이 j에 배정. 단 j ∈ feasible_bays[b]로만 도메인 제한 :1640. 파생: wl[j](베이별 가중 workload), hi/lo(max/min load), z2=hi−lo.
제약
  • 각 블록 정확히 1베이: Σⱼ x[b,j] = 1 :1644
  • workload: wl[j] = Σ_b workload_b · U[j] · x[b,j], U[j]=round(bay_u[j]·1000) :1650
  • 불균형: z2 = AddMaxEquality(hi,wl) − AddMinEquality(lo,wl) :1660
  • 선택적 area-time 용량(cap_alpha) / count cap(count_cap_beta) — LEAN은 미전달 → OFF :1694,1733
  • 크레인 제약 없음 · ENTRY/EXIT 시각 없음 — 순수 배정 문제
목적식
Minimize( c2·z2 + c3·1000·Σ (s_max − pref[j])·x[b,j] )
c2=round(w2), c3=round(w3) :1665. z1(tardiness) 항 전혀 없음 = z1-blind :1675.

warm-start: _balanced_seed를 AddHint로 주입(나쁜 hint는 OR-Tools가 무시). cap 완화 self-fallback: INFEASIBLE이면 count_cap→area_cap 순으로 떼고 재호출 — 배정을 절대 잃지 않음 :1769. (이 재귀는 ①→① cap 완화이지 ③→① 컷이 아님.)

decouple: 위치·방향·시각을 전혀 안 다루고 오직 배정만 → 변수가 O(블록×베이) BoolVar로 축소.

역할: 고정된 한 베이의 배정 블록들에 대해 시간을 먼저 고정(entry=R, exit=R+P)하고 위치(x,y,orient)만 크레인-안전하게 탐색.

"시간 고정"의 의미 :558,598
모든 블록이 entry=R, exit=R+P를 목표 → due ≥ R+P면 tardiness=0. 시각을 결정변수에서 빼고 위치만 자유변수로 만든다.
위치 결정 (3단 폴백) :594-643
  1. at-R abut + grid scan: order대로 R 시점 밀착 후보 + 베이 전체 격자 스캔(_ft_search_pos), 시간-겹침 집합(_ft_interacting)에 대해서만 충돌/크레인 접근성 검사
  2. delayed: 실패 시 placed exit 시각들로 entry를 오름차순 이동 :608
  3. forced: 모든 placed exit 이후 빈 윈도우(상호작용 0 보장) :619 ← tardiness 발생 지점

크레인 j≥k 보장: _ft_search_pos가 시간-겹치는 placed 블록들에 대해 충돌/entry/exit 접근성 검사 → 통과 위치만 채택. coexit는 _CRANE_COEXIT(기본 ON).

decouple: ①이 배정을 고정 → 각 베이가 독립(베이별 따로 디코드), 시간을 R로 고정 → 위치 탐색만 남음.

③ 타이밍 오라클 — _cpsat_bay_timing_verified :2617

CP-SAT per-bay벤더스 서브문제★ 최고 ROI (3.5s에 −49%)

역할: ②가 만든 고정 레이아웃(x,y,orient 불변) 위에서 ENTRY/EXIT만 재배치해 베이별 tardiness(z1) 최적화. z2/z3는 증명적으로 불변(위치를 안 건드림).

입력
prob_info, bays, results(②출력), deadline, lb_skip=True
출력
개선된 solution 또는 None(구조적 개선 없음/deadline)
결정 변수
블록당 e[b] IntVar(entry, 도메인 [R[b], H]) 단 하나. exit는 선형식 e[b]+P[b](WLOG 최적). tard[b] ≥ e[b]+P[b]−D[b] :2877.
제약 — 1-D disjunctive 스케줄링
기하는 고정 위치에만 의존 → 상호작용 쌍마다 5개 시간-독립 boolean을 1회 사전계산(collision/entry×2/exit×2) :2838 → 각각을 interval disjunction(half-reified BoolOr) :2847. per-bay 독립(베이 간 결합 없음). ENTRY≥R은 e 하한 도메인, EXIT−ENTRY≥P는 exit=e+P 정의로 자동.
목적식
Minimize( Σ tard ) = z1 tardiness만 :2881.

warm-start: AddHint(e[b], cur_entry[b])(현 스케줄이 feasible incumbent). lb_skip: 베이 현 tardiness가 _bay_tardiness_lb(어떤 스케줄로도 못 깨는 하한)와 같으면 그 베이 건너뜀(예산 절약). 베이별 best-of: new_tard<cur_tard일 때만 갱신 → 절대 악화 없음.

decouple: ①배정·②위치 고정 → 남은 건 베이별 1-D entry 변수의 disjunctive tardiness 최소화. CP-SAT가 실제로 풀 수 있는 작은 문제(이래서 3.5초에 −49%).

_build_operations: flat assignment → operations dict(str(time)→[op]). 같은 시각 내 EXIT가 ENTRY보다 먼저, 그 다음 block_id 순(check_feasibility 요구 순서). 순수 포맷 변환, 엔진 아님.

_trivial_solution (절대 폴백 = never−1의 마지막 보루): EDD 순 정렬 후 각 블록을 _force_in_bay(빈 시간 윈도우 = 상호작용 0 → 크레인/충돌 vacuously 만족)로 직렬 배치. 같은 베이 블록이 시간상 절대 안 겹치므로 항상 feasible. 베이 선택은 w1·tard+w2·z2_proxy+w3·pref 최소화.

핵심 인사이트 3가지

1. decouple = 작은 문제 3개로 쪼개기

① 배정 고정 assign[b] → ② 각 베이 독립 + 시간 R 고정해 위치만 → ③ 위치 고정 x,y,orient → entry 1-D disjunctive만. 각 단계가 앞 출력을 상수로 흡수해 결합 NP-hard를 풀 수 있는 작은 문제 3개로 만든다. 동시에 풀면 폭발하는 걸 순차 분리로 회피.

2. ③→① 컷 환류가 없다 — 진짜 LBBD가 아닌 1-pass

③ 타이밍 오라클이 산출한 잔여 tardiness를 ①배정으로 되돌리는 no-good / tardy-cardinality 컷이 LEAN 분기에 전혀 없다. _cpsat_assignment는 LEAN에서 단 1회만 호출(:5640). 코드베이스의 no-good-cut 상태(:1896, :2059)는 별개의 ALNS 경로 소속이고 LEAN은 호출 안 함.

→ ③의 z1 정보가 ①로 환류되지 않으므로 진정한 벤더스(LBBD)가 아니라 단방향 decomposition. 이것이 벤더스 컷 환류 레버가 들어갈 정확한 빈자리다(③→① tardy 컷 추가 = 1-pass를 진짜 LBBD로 승격).

3. z1은 ③에서만 다뤄진다 → LEAN이 z1-약한 구조적 이유

단계z1(tardiness) 처리
① 배정z1-blind — 목적식에 tardiness 항 없음(z2+z3만). 한 베이에 시간-충돌 블록을 몰아넣을 수 있음
② 위치entry=R로 z1=0 시도, 단 congestion 시 delayed/forced → tardiness 발생
③ 타이밍고정 레이아웃 위에서 베이별 최적 재타이밍으로 z1 깎음 — 단 ②가 정한 배정·위치 안에서만

①이 z1을 안 봤으므로 배정 자체가 나쁘면, ③은 베이별 LB(_bay_tardiness_lb) 이하로 절대 못 내림. → LEAN = z3 탁월(①이 선호 베이 유지) · z1 약(①이 z1 무시). gassign(z1-aware)·box(z1/density)가 이를 보완하는 best-of 후보인 이유.

그래서 다음 레버

이 분해가 가리키는 단 하나의 정확한 빈자리: ②번 인사이트의 컷 환류.

  • ③ 타이밍 오라클 → ① 배정 마스터로 tardy-cardinality 컷 환류. 이미 있는 오라클이 "이 배정은 베이 j에서 tardy ≥ N개라 나쁘다"를 알아냄 → 그걸 제약으로 ①에 되돌려 재배정 → ① z1-blind 결함을 닫음. 1-pass를 진짜 LBBD로 승격.
  • 구현 싸다 — ①·③ 모델은 그대로, 둘 사이 루프 + 컷 1종만 추가. ① 변수가 이미 x[b,j]라 no-good 컷(Σ x[b,j] for tardy set ≤ k−1) 자연스럽게 표현.
  • 위험: 루프 반복이 _ll_total 예산 안에서 수렴해야 함 → 1~2 iteration 캡 + deadline 가드. never−1은 기존 폴백으로 유지.

대안: ② forced-placement(tardiness 발생 지점)를 z1-aware order_key로 줄이기 / ① 목적식에 z1 proxy(area-time 용량 cap) 부활 — 단 둘 다 컷 환류보다 간접적.
