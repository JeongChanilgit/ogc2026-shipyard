0. 문제와 목적함수 (무엇을 푸는가)

The Grand Shipyard Puzzle. 조선소 블록을 베이에 배치·스케줄. 블록당 5D 동시 결정: ① 베이 j · ② 위치 (x,y) · ③ 방향 o · ④ ENTRY 시각 · ⑤ EXIT 시각 (=ENTRY+처리시간 P, WLOG).
제약: 모든 블록 정확히 1 베이 · ENTRY≥release · EXIT−ENTRY≥P · 베이 경계 · 동일층 충돌금지 · 크레인 수직접근(j≥k) = 시간 겹치는 두 블록은 footprint 비겹침.
목적함수 (가중합 최소화):
w1·z1 (tardiness, 지배적)
w2·z2
w3·z3 (preference)
z1 = Σ tardiness · z2 = max 부하 불균형 · z3 = Σ(선호편차) · 가중치는 인스턴스마다 자릿수 단위로 다름 (w1 667~29,600) → weight-adaptive 필수
점수: infeasible/timeout/crash → −1 (평균 −R/2, 최대 손실). feasible → R − nb (엄밀히 더 나은 팀 수). ⇒ never −1이 1순위, 그다음 총 obj.

2. 세 엔진 (누가 무엇을 푸는가)

gassign 주 엔진 · src/gassign.py
  • 철학: 배정 자체를 z1-aware로 (어느 블록을 어느 베이에)
  • 구조: B1 배정 ↔ LBBD ↔ B2 배치 → B3 타이밍 (§3)
  • 이기는 곳: w1 큰 congested set2 (z1 대폭↓)
  • 실적: set2 −95.7% (vs 옛 레거시-only)
legacy set1 챔피언 · myalgorithm._legacy_algorithm
  • 철학: z1-blind 배정 + 강력한 floor + 타이밍, 多모듈
  • 모듈: fastfloor·baseline_greedy·uconstruct·rebuild·regime·z3race…
  • 이기는 곳: 작고 congested한 set1 (z1=0 19/20)
  • 저-TL/운영 경로. set1에서 gassign보다 강함
box best-of 후보 · src/boxsolver.py
  • 철학: 선호배정 고정(z3≈0) + 시간-확장 co-presence 패킹
  • Phase1 배정 → Phase2 box-decomp CP-SAT → reassign/feasspill
  • 이기는 곳: w3 큰 less-congested (낮은 z3로 z1=0)
  • 항상 best-of로 안전 합류 (회귀 불가)

3. gassign 내부 — B1 → B2 → B3 + LBBD 주 엔진 심층

"decoupling" 기법: 배정 → 위치고정 → 1D 타이밍. 각 단계가 5D 결정의 일부를 담당.
B1

z1-aware 전역 배정 (CP-SAT master) gassign.py:177 _solve_master

변수 x[b,j](배정)·entry·tard. 면적-시간 cumulative 완화(동시존재 면적합 ≤ 베이용량)로 시간적 과포화 베이 prune. 목적 = 체커와 단위일치 c1·z1 + c2·z2 + c3·z3.

★ 이번 세션 핵심 레버 (C3_MULT=2.0): c3 = round(w3 × 2.0). master가 area-time 완화라 "spill하면 z1 준다"를 과대평가→과-스필. z3 가중치를 ×2로 올려 master가 블록별로 spill을 더 엄격히 판단 → z1 비용 없이 z3 −16%. gassign.py:362

위치 고정 → crane/충돌이 시간 무관 → 타이밍이 1-D disjunctive tardiness로 환원 → 베이별 최적 entry/exit를 CP-SAT로. (footprint 겹치는 쌍만 시간분리.)

LBBD 루프: master(완화)가 z1-aware 배정 제안 → B2 디코더가 기하로 검증 → 실패/tardy면 cut으로 master에 "실제로 가능한 것"을 가르침 → best TRUE z1 채택. base-first depgroup race로 z3 tie-break(never-worse).
