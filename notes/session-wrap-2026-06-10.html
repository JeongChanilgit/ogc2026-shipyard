발견 prob_13 — 비단조 postprocess (다음 세션 레버)

  • tl=100서 z1=1 / obj 245,705 인데, tl=300·1000서 z1=10 / 330,342 로 시간 줄수록 악화(idle 아님 — cum_level 529s + bbox_pack 427s, 986s 다 씀).
  • 긴 postprocess가 z1을 1→10으로 올리며(−167K) z3만 약간 낮춤(+83K) → net obj 더 나쁨인데 그걸 채택. 초반 통과한 더 좋은 해(z1=1)를 retain 안 함.
  • best-of-N(OGC_PP_MULTISTART)은 무효 — postprocess가 예산을 꽉 채워 restart 자리 없음(ON==OFF 동일).
  • 레버 postprocess 궤적 전체에서 best full-obj 유지 또는 스케줄 개선 → prob_13 ~26% 개선(330K→245K), 일반 fix일 가능성. z3 레버(고갈)보다 유망. 단 stage별 obj 계측 필요 → 집중 작업.

세션 채택 / 기각 요약

  • SHIP Adaptive raster floor 게이트 — 짧은-tl z1 catastrophe(obj 6.5M~46M) 제거, 긴-tl 무영향. v08 번들(미제출).
  • 기각 CP-SAT z3 재배정 — z3는 packing-blocked(z1↔z3 Pareto). 선호 베이로 몰면 z1 20~180배 폭발. 이미 존재하는 seed가 옳게 거부됨.
  • 기각 Front B 튜닝 · best-of-N — 노이즈 수준/비일관. gated OFF.
  • 인증 −1 / 타임아웃 견고 — tl=60(eval 바닥 아래)에서도 실패 0.
  • gated floor budget cap(OGC_FLOOR_BUDGET_PCT) — 짧은-tl 소형 catastrophe(prob_1 z1=172→0) 완화하나 대형 trade-off로 default OFF.
