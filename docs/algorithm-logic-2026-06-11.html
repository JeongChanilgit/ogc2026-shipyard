크레인 j≥k 규칙 상세 utils.py:22
크레인은 수직 전용. 신규 블록 layer k 하강 시, 기존 블록 layer j와 같은 높이 통과 → j ≥ k인 모든 쌍만 충돌 검사. j == k = 최종 안착 충돌 (빨강), j > k = 하강경로 sweep 충돌 (주황), j < k = 기존층이 아래라 절대 안 닿음 → 무시 (회색). EXIT(상승) 시는 대칭.
다이어그램 B — 크레인 j≥k 규칙 베이 단면도
크레인이 수직으로만 이동하므로, 신규 블록 layer k가 기존 블록 layer j(j≥k)를 통과한다. 이 규칙이 블록을 시간으로 직렬화하게 만들어 Z1 상승의 근본 원인이 된다.
